\begin{abstract}
Language models can use skills supplied in context, including formulas, rules
and step-by-step instructions, to solve tasks. Understanding how they use
these skills matters for deciding when injected information contributes to
computation and when its source must remain accessible. However, the relation
between skill-state transferability and continued dependence on the skill
source remains unclear: when transplanted states can no longer change a
model's behaviour, has the model stopped needing the skill? We compare two
interventions along model depth. We transplant correct-skill span states into
a wrong-skill run and measure recovered task performance. Separately, we
block subsequent attention to the skill from a specified layer in the
correct-skill run and measure the performance loss. Across three models from
two families on screened subsets of MedCalc and TheoremQA, transfer weakens
before source dependence subsides. The ordering persists when both
interventions are evaluated on common eligible items. In this intermediate
interval, skill states have little corrective effect in the receiver, yet
removing access to the source still harms the original computation. Content,
position and repeated-replacement controls help delimit this finding.
Failed skill transfer alone is therefore insufficient evidence that a model
has finished using its contextual skills, motivating separate evaluation of
transferability and source dependence when reusing skill representations.
\end{abstract}
