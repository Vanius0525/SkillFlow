\section{Related Work}
\label{sec:related}

\paragraph{Transferring task behaviour through internal states.}
Task vectors summarize demonstrations as internal vectors that can steer
a new example \citep{hendel2023taskvectors}. Function vectors identify
attention-head outputs that transmit a task's behaviour across contexts
\citep{todd2024functionvectors}. Natural-language instructions also yield
transferable components \citep{davidson2025prompting}, and instruction
patches can interact across layers \citep{bigoulaeva2026instructionvectors}.
The effect of transfer varies with the task and intervention time
\citep{jit2025taskrepr}. These results establish useful transfer settings.
We examine how transfer changes across depth relative to the original
execution's continued dependence on its skill source.

\paragraph{Tracing context use and execution history.}
Cumulative context masking tests whether a model still needs source tokens
at later layers \citep{sia2024incontexttranslation}.
Instruction-span and final-position patches can reveal different effects
\citep{onset2025instruction}. Joint analyses of masking and state transfer
locate subtask execution across layers \citep{yang2025internalcot}.
Activation patching, the replacement of selected
hidden states by states from another run, requires matched controls and
careful implementation
\citep{zhang2023bestpractices,heimersheim2024patching}.
Effects can depend on interactions among the intervened components
\citep{vaidyanathan2026mediators}. We pair full-depth transfer and masking
profiles, then test source states together with their attention caches.
This connects our work to PrefillNotes \citep{li2026prefillnotes}, which
shows that precompiled skill caches can be repositioned and composed with
a target context. Our focus is when residual-state reuse weakens while
source access remains important, and how replacing source-position caches
affects that separation.

\paragraph{Skills and reusable context.}
Agent Skills organize instructions and resources for on-demand use
\citep{zhang2025agentskills}. Benchmarks measure skill retrieval and
application \citep{su2026srabench,skillsbench2026,sweskills2026}, while
matched-budget evaluations show that their benefit depends on the available
computation \citep{hajimiri2026budgetskills}. We fix the selected skill and
study how its loaded content supports execution.
A related direction compresses context into aggregated activations
\citep{ardoin2026promptcompression}, learned summary tokens
\citep{mu2023gist}, compact hidden states \citep{ge2024icae}, or weight
updates \citep{doc2lora2026,deepcontextdistill2025}.
We study naturally occurring states through interventions, providing tests
of reuse and source dependence that complement trained compression methods.
