\section{Introduction}
\label{sec:intro}

\paragraph{Relevance to the Web and to this track.}
Web agents use retrieved skills and reusable workflows to act across sites
and services \citep{wang2024awm,wang2026webxskill}. We ask when the internal
states produced from a loaded skill can support another execution.
This question concerns the reuse of external knowledge in agentic
information access and connects our study to the Search, Recommendation,
and Retrieval-Augmented AI track.

An Agent Skill packages task instructions, scripts and supporting resources
around a \texttt{SKILL.md} entry point, which an agent loads when needed
\citep{zhang2025agentskills}. We study the instruction content of a loaded
skill. A model can apply that content successfully, but how much of the
resulting ability can be reused through its internal states? Reusing states
from an earlier execution is an appealing way to share skills and avoid
repeated processing. It requires understanding which states contribute to
the ability and what else those states need in order to work.

A useful starting point is to move skill states into an execution using an
unrelated skill and measure the benefit restored. Task and function vectors
show that internal states can transmit task behaviour across contexts
\citep{hendel2023taskvectors,todd2024functionvectors}. Such transfer may also
depend on the computation surrounding the states and on further access to
the source. We therefore ask: \emph{how does the ability to transfer a
skill's states relate to the ongoing need to read that skill?}

We follow both properties across model depth. First, we replace the hidden
vectors at skill-token positions in a wrong-skill execution with vectors
from a correct-skill execution. These residual states are the vectors passed
between successive model blocks. Second, we block attention to the skill
from a chosen layer through the rest of the original correct-skill execution.
This measures performance retained without further source access.

Figure~\ref{fig:teaser} previews the result. Early residual-state replacement
recovers much of the skill's benefit. Deeper in the model, transfer becomes
weak while blocking subsequent skill attention still damages the original
execution. This ordering recurs across three models from two families and
two task domains, including comparisons on identical eligible questions.
We use content, position and cross-question controls to establish the
effective early probe before interpreting this separation.

What can restore transfer in that interval? Residual replacement leaves the
receiver's attention cache in place. This key/value (KV) cache stores
vectors that later tokens read through attention. Jointly replacing the
skill's residual states and its source-position cache entries restores
substantial late transfer in Qwen3-8B/MedCalc. Cutting subsequent reading
then removes most of the recovered effect. The source cache and continued
reading therefore matter alongside the residual vectors themselves.
Earlier reader computation remains unchanged in these tests, so the
intervention targets specific source components rather than replaying the
donor's complete execution.

Work on layer-wise computation and reusable skill caches highlights how
depth and stored context shape model behaviour
\citep{yang2025internalcot,li2026prefillnotes}. We connect these questions
through three contributions. First, we validate an early skill-span
transfer probe using content, position and cross-question controls
(\S\ref{sec:battery}). Second, we identify a depth interval in which residual
transfer is weak while the original execution still depends on skill
attention (\S\ref{sec:depth}). Third, we isolate the contributions of
source-position caches and subsequent reading to late transfer in one
model--task setting (\S\ref{sec:mechanism}). Together, the results identify
concrete conditions under which skill states can be reused: the accompanying
source cache and the access available after transfer both deserve explicit
tests.
