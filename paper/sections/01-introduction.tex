\section{Introduction}
\label{sec:intro}

\paragraph{Relevance to the Web and to this track.}
Web agents rely on machine-readable instructions and descriptions of tools
and services to understand how to act across sites
\citep{wang2024awm,wang2026webxskill}. Agent Skills package such procedural
knowledge for reuse. We ask how a model uses a loaded skill and when the
internal states it produces can support another execution. This connects
our study to the Semantics and Knowledge track's interest in
machine-readable descriptions that help agents understand and use Web
resources, and in knowledge representations that support intelligent
agent behaviour.

Agent Skills package instructions, scripts and resources around a
\texttt{SKILL.md} entry point \citep{zhang2025agentskills}. We study the
instruction content after the skill has been selected. For example, a
calculator skill supplies a formula, input conventions and worked steps;
the model must apply them to a new question. Web agents similarly use
machine-readable descriptions of tools and services
\citep{wang2024awm,wang2026webxskill}. Understanding the limits of reusing
their processed representations connects this study to the Web's semantics
and knowledge infrastructure. Our experiments test controlled skill-based
question answering, rather than interactive browsing.

Task and function vectors show that internal states can transmit task
behaviour across contexts \citep{hendel2023taskvectors,todd2024functionvectors}.
However, restoring a corrupted execution and disrupting a successful one
measure different intervention effects; one need not determine the other
\citep{heimersheim2024patching}. Our contribution is to measure how those
effects separate across depth for supplied skills, and to test a specific
component omitted by residual-state transfer.

We first validate a transfer probe that copies hidden vectors at the skill's
token positions from a correct-skill donor into an equal-length wrong-skill
receiver. Content, position and cross-question controls test whether its
early benefit carries structured skill information. We then compare this
probe across all layers with cumulative skill-attention knockout in the
original correct-skill execution. This knockout blocks both access from post-skill tokens
and attention within the skill text. It therefore measures aggregate
skill-attention dependence, not post-skill-only dependence.

Figure~\ref{fig:teaser} previews the two levels of evidence. The main
finding is a depth interval in which residual transfer is weak while
skill dependence remains high. The ordering of their first half-effect
crossings recurs in all eight comparisons across four main models,
using common eligible question IDs within each comparison; a smaller-model
scale check is reported in Appendix~\ref{app:scale-check}. These are
conditional effects on screened populations, and matching IDs does not
make the donor and receiver execution backgrounds identical.

To probe one possible contributor to the late transfer deficit, we replace
the skill-position key/value (KV) caches that residual replacement leaves
unchanged. In a focused Qwen3-8B/MedCalc experiment, joint state and cache
replacement raises layer-$16$ accuracy from $3.5\%$ to $42.1\%$; a subsequent
post-skill-to-skill cut reduces it to $7.0\%$. This identifies a partial repair,
not a complete account of the failure. The intervention changes which
skill-position caches are available across layers, does not replay earlier post-skill
computation, and remains far below the donor's $100\%$ accuracy on this
freshly screened set. The same layer-$16$ comparison shows positive
repair and recutting effects across all eight main model--task settings,
with different effect sizes and independent baseline screens.
Distinguishing cache coverage from more specific
state--history interactions requires additional controls.

The experiments follow this evidential progression: validate the early
probe (\S\ref{sec:battery}), establish the depth separation
(\S\ref{sec:depth}), and measure the effect and limits of partial cache
repair (\S\ref{sec:mechanism}). The resulting contribution is a replicated
depth ordering under the tested transfer and knockout protocols, together
with a localized skill-cache intervention that recovers part of late
transfer. It does not establish that the skill is fully internalized at a
particular layer or that cache mismatch uniquely explains weak transfer.
