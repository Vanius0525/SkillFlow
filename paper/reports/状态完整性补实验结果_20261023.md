# 状态完整性补实验：结果与论文含义（2026-10-23）

本轮已完成用户保留的实验②（状态完整性分解）和③（内容/层覆盖对照），实验①全层双曲线复测已取消。未修改论文或Overleaf。

## 最重要的新增认识

在本轮固定候选池中，SC已使全部skill位置、全部层的KV与donor精确对齐；再显式覆盖一次（SC_exact）不改变任何生成token。但修复仍强烈依赖S发生在哪一层。因此“漏复制source缓存”不能单独解释剩余晚层缺口。非source缓存背景仍未匹配，而复制完整prefix缓存可逐token复现donor。

这不是推翻“完整执行状态未复制”的总解释，而是把它具体化：完整source状态本身不一定足够，接收执行的非source状态是必须明确控制的因素。该认识比单纯“加缓存有效”更具体，但尚不是新的通用压缩/修复算法。

## 设置和核验

- Qwen3-8B / MedCalc，历史冻结124候选题、14个计算器skill；不是全量benchmark。BF16/eager/split-prefill/greedy，1536新token上限。
- 正式6076条＝124题×49条件，两个3038条分片；另有14条gate。GPU任务分别于2026-10-23 17:36:15和15:23:34成功结束。
- 两分片及gate文件SHA、唯一键/完整网格、生成token数量、已声明依赖文件SHA通过。独立CPU进程对6076条正式结果正序/逆序重新评分一致，gate另重判14条。
- 两种接收背景的完整prefix复制均124/124逐token等于donor；wrong背景的自身source-cache写回124/124等于receiver。未发现仪器失败。
- SC与SC_exact在两背景×L8/16/24的744对生成中全部逐token相同。运行内逐元素写入检查及保存的逐层K/V审计显示SC的全source缓存误差均为0；非source缓存不等于donor。离线审计核查这些记录，没有再次运行模型或取回完整KV张量。
- 原始压缩输出留在SSD v2，约35.1MB；本地只取回汇总与二值标签，不取回回答正文。

## ②怎样回应状态复制不完整的质疑

1. **不是简单少复制了几层source KV。** SC在三个干预层均有完整donor source KV，显式补写没有额外作用；但SC@8与SC@24差距仍大。固定source缓存以后，剩余差异位于非source执行状态背景。
   - 不匹配背景，SC@8−SC@24：+66.1 pp，95% CI [49.3, 78.5]。14组中12组为正、2组相等。
   - 中性背景，SC@8−SC@24：+64.5 pp，95% CI [40.5, 82.8]。14组中11组为正、2组相等、1组反向。
   - L8的SC未截断；L24在不匹配背景截断3条、中性背景0条。将截断结果作对该差值最不利的重判后，不匹配背景仍有63.7 pp差距，中性背景仍64.5 pp。
2. **全source缓存单独迁入仍不充分。** C_all仅29.8%/25.0%；完整prefix缓存复制达到donor的97.6%，且输出逐token相同。后者是正控制，不能作为新颖性本身。B_only也低，说明不能把贡献理解为source与非source两部分简单相加。
3. **重算后续prompt可大幅恢复，但不是数值等价保证。** 两背景均120/124（96.8%），接近donor121/124。但仅48/124生成token完全相同；重算后的非source缓存仅1/124完全匹配donor。BF16和不同prefill计算形状下，不能声称严格等价。
4. **SC不总优于C_all。** L24不匹配背景SC25.8%低于C_all29.8%；L16两者差值的整组区间在完整池和共同筛选池包含0，不能把每层的额外状态收益都当成稳定发现。

pp指准确率差的百分点。95% CI为按skill整组有放回重采样10000次后差值的2.5%和97.5%分位数，衡量该抽样设定下的不确定性。同skill的题目不被当成独立样本。区间为探索性结果，未做多重比较校正；14组仍有限。

固定位置和层覆盖后，正确内容的效果超过两种控制，支持内容特异性，不是仅靠同样大小的写入或一般扰动。四个预设8层窗口均只得到较低准确率：

|---|---:|---:|

## 筛选、原稿对齐与不能跨越的边界

- 新协议wrong基线筛选保留114题/14组：donor正确、wrong及no-skill错误；L16 S/C/SC为3.5%/7.0%/42.1%，与原稿主案例数值一致。保留完整124题主表，避免只报告有利筛选。
- neutral单独筛选为114题/13组，与wrong筛选不是同一人群；两背景共同失败集为111题/13组。共同集L16 SC为42.3%/28.8%，但不匹配减中性SC的配对组级区间包含0，不能宣称两背景存在稳定优劣。
- 本轮中性背景也有source完整时的跨层缺口，说明这一固定层现象不只出现在不匹配skill背景。但实验①已取消，本轮没有独立复测原全层T/R分离，不补充那部分稳健性证据。
- 不识别非source缓存中具体存了什么语义变量，不证明唯一“错误结论”机制，不分离prefill和decode阶段。
- 不声称用source缓存替换就可以实现廉价可部署复用：完整copy使用同题donor计算，完整后缀重算也是昂贵对照。
- 未验证未见skill上的修复预算预测，未扩其他模型/benchmark。相关理论的未验证margin充分条件仍不是本轮创新支柱。

## 值得深挖的问题（候选，未确认独立新颖性）

固定完整source缓存以后，能否从可提前测量的接收状态特征，预测必须重算哪些reader位置或层？触发证据为SC@8/@24在同source下相差64.5–66.1 pp，且完整后缀重算接近恢复。最小下一步是有限重算预算对照、按skill留出验证；若只完整重算有效、规律依赖同题donor不可用信息，或PrefillNotes等近邻已覆盖相同规律，则独立价值下降。本轮不自动启动该后续实验。

## 对原论文结论、创新性和启发性的判断

总体有利于经验结论和解释深度，不能直接换算成“正确概率增加多少”。本轮是同一模型、同一冻结候选池上的针对性控制，不是新benchmark或全部八组合的独立外部复现。

| 原主张或可能的解释 | 本轮影响 | 应采用的表述 |
|---|---|---|
| 使用skill与复用其内部状态需要分别测量 | 支持更强，固定层中性背景同样存在复用缺口 | 在本设置中，来源信息完整也不保证在既有接收状态中恢复 |
| 原全深度T<R排序 | 没有被推翻，但本轮不新增完整曲线稳健性证据 | 保留原范围和协议限制，不据本轮声称已解决全部实现混杂 |
| 晚层失败主要只是漏了低层source KV | 单独解释不够 | SC已全层source对齐，仍有大幅跨层差距，非source背景必须纳入解释 |
| 完整执行状态没有复制，所以仍会失败 | 仍然成立 | 本轮把这一笼统解释拆成可测的source与非source部分，没有反驳该总命题 |
| SC是普遍充分、各层更优的修复方法 | 不支持，反例更明确 | SC部分恢复且具有层/背景依赖；L24不匹配背景不优于C_all |
| 数学充分条件已经解释行为恢复 | 仍未验证 | 覆盖身份关系得到运行内核验，margin条件和有用敏感度界没有验证 |
| 已有指导新skill的通用预算规则 | 尚无证据 | 仅提出后续可证伪的预算预测问题，本轮不宣称解决 |

较有价值的叙事增量是：从“加缓存有用”推进到“固定完整source缓存，恢复仍受接收端其他状态影响，而且这种影响依赖干预深度”。可据此提出更好的评测原则：报告source复制覆盖、接收背景、历史重算范围及相应成本，不能把状态迁移失败直接等同为skill信息消失。

但缓存历史与下游重算已有直接近邻（本项目先前调研的PrefillNotes等）。全copy或全suffix重算有效本身不是新方法。创新性增强来自具体的控制、量化与适用边界，是否足以形成顶会级贡献仍需与近邻逐项对照，或进一步得到独立skill上可预测、预算受限的复用规律。

此外，中性背景不是完全无干扰，混合cache可能产生不自然的执行状态；本结果不是证明skill不可压缩或无法学习可迁移表示。只有14个skill组，部分组反向，不能用汇总大差值抹掉异质性。


## 术语澄清：不是“与skill无关的缓存”

这里的“非source缓存”严格指位置：skill文档token位置以外、已经处理过的prompt位置的KV，主要包括题目和模板位置。它们可能已经编码了读取/应用skill产生的信息，不能叫“与skill无关的信息”。本轮没有解码出这些位置存放的具体语义，也未定位最小必要位置集合。

对每道题，在最后prompt token重算之前，SC@8/SC@16/SC@24的全层source KV都等于同一个donor source KV；最终token、模型参数、位置、mask和解码规则相同，其他位置的缓存却随此前干预深度不同。此时准确率变化说明source文档位置的缓存本身不足以决定复用效果。这个对照收窄的是执行状态层面的解释，不是对skill语义存储位置的唯一定位。

相比原稿“状态迁移晚层弱、加缓存部分修复”，新增的是“即使source覆盖已完整，迁移仍取决于接收执行已经形成的其他缓存背景”。它支持评测时控制接收状态、研究必要重算范围；不证明必须搬走所有题目缓存、不证明skill不可压缩，也不等于已提出预算受限的新复用方法。


## 与当前数学段落的兼容性及表达建议

已对照当前sections/03-problem-formulation.tex、appendix/cache-coverage.tex、appendix/behavior-recovery.tex和结论；本轮未编辑这些稿件文件。

1. source覆盖命题：SC补齐全部source KV但未要求其他prefix缓存等于donor，新数据与此一致，并在本轮BF16条件中用运行内审计核验了覆盖。原附录“BF16 source差异尚未测量”的事实状态已过时，修稿时可用具体结果替换，但只涵盖已测Qwen/MedCalc的SC条件。
2. 距离恒等式：原文只说明被替换坐标使cache的欧氏距离不增，不保证实际输出误差或准确率单调变好，新结果未与之冲突。不能把它升级成行为改善定理。
3. margin充分条件：有用的敏感度上界和逐步margin条件依然没有验证。完整prefix复制时输出一致不等于验证非零误差条件下的保证；这里的必要限定仍应保留。
4. 原结论已有“深度分离”和“部分L16修复”的范围限制，不需要因为新结果全面收窄；本轮也没有补做实验①，因此原全层协议差异等边界并未消失。

可以减少的是重复且已被具体对照回应的泛泛防御，用正面量化陈述替代：全source对齐已核验、显式补写逐token无变化、固定source后的跨层差距、匹配覆盖下内容特异性。不能删去样本/模型范围、充分条件未验证及原全层复测未补的限制。将同一边界在主文说清一次，细节集中附录；无需反复提前否定，也不扩大实际声称。
