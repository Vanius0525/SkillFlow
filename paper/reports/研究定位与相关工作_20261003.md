# 当前论文的竞争力与研究定位
## 结论、最近邻实验、last-token 与 RSI
2026-10-03｜依据当前 paper 正文、已有实验产物与一手文献

**结论：值得继续做，有形成 A 类会议论文的实质基础；但当前版本还不足以让我判断“已经达到较有把握中稿的水平”。** 这不是课题已被完全覆盖，而是当前最强发现尚未被充分解释，部分创新叙事又已经落在近邻工作的覆盖范围内。录用受审稿与会议匹配影响，不能给出可靠的中稿概率。

**最有竞争力的点：可转移性与持续读取依赖分离。** 在同一设置中，某层的 skill 状态已经不能有效移植给错误运行，但正确运行仍依赖对这些位置的 attention。这比“skill 不只存在于最后一个 token”更值得主打。它提出了新问题：不能移植，是信息消失了，还是接收方已有计算状态与移入的程序不兼容？后者目前只是候选解释。

**当前可写的三项贡献。** 一是以正确/错误的等长程序文档作对照，定位可恢复效果的原位 token span（连续位置范围）；二是测量位置结构及 rank（保留的独立方向数量）对真实生成恢复的影响；三是配对比较状态移植与读取敲除，识别不同的深度边界。单项工具大多已有先例，价值来自科学发现和严格比较。

**不能继续主打的说法。** 首次发现 prompt 的内部表示、首次注入 last token、首次发现多位置表示，均不成立。“长输出必然不能被单向量控制”“skill 只存在于自己的 token”也超出了证据。

**WWW 需要单独判断。** 当前无工具的 MedCalc/TheoremQA 实验更自然地属于模型机制解释。WWW 2027 官方要求明确的 Web 科学问题，仅使用 Web 数据或 API 不够。若不准备把问题落到真实 Web 程序文档、检索或 agent 工作流，ML/NLP 会议的范围更匹配。[R1]

**投入建议：先补能改变结论的判别实验，再扩数据规模。** 优先顺序是：晚层接收态兼容性 → 连续性与语义覆盖控制 → 公平的单向量基线。若坚持 WWW，再验证机制导出的 Web 系统设计。RSI 建议独立推进，不宜强行并入这篇稿件。

阅读指南：第 2 页审查当前证据；第 3–4 页比较八篇最近邻；第 5 页回答注入设计；第 6 页讨论 RSI；第 7 页列补实验和一手出处。

证据说明：本报告没有重新运行模型、独立复算所有历史结果或修改 LaTeX。项目数字来自当前正文及本地产物；外部结果为论文作者报告。判断以已检索文献为限，不构成首创证明。详细调研记录见 paper/audit/RESEARCH-context-lasttoken-rsi-20261003.md。

# 1　当前证据能支持什么

**行为收益是真正的研究起点。** 当前正文报告 1,100 道临床计算题：正确 skill 准确率 74.2%，无 skill 34.5%，错误 skill 31.5%。这说明程序内容比仅仅“有一段 skill 文本”更重要，但不直接定位内部算法。

**span 恢复有力，但样本口径必须写清。** 主要因果子集为 135 题、14 类 calculator，是经过筛选的样本。原位 span 在一个层恢复 0.89，而末位置很低。恢复率 ρ =（干预准确率 − receiver 准确率）/（donor 准确率 − receiver 准确率）；donor 是提供状态的运行，receiver 是接收状态的运行。ρ=1 表示恢复该对照下的全部增益，ρ=0 表示无恢复；0.89 不是全 benchmark 的准确率或“恢复 89% 的算法”。

**深度分离是主线候选。** Qwen3-8B 主结果中，span 转移的下降边界约在 L13，累计读取敲除的对应边界约在 L25；在两个任务域、两个模型家族中有复现。不过，两种干预分别考察恢复能力和读取依赖，不能单凭边界不同就宣称发现了一个确定的“编译—执行交接点”。

**rank 曲线是操作性测量。** 保留位置均值后，前 32 个方向恢复约 0.12，前 128 个约 0.77。Qwen 宽度相差四倍，恢复曲线半幅拐点约为 43/47，反驳本实验中的宽度正比预测。它不是整套模型算法的内在维度，也不是普适 scaling law；保留均值时总矩阵 rank 还可能增加一维。

**必须修的混杂：连续性。** 256 个位置的一块注入恢复约 0.371，分成 32 块约 0.081；但两者选了不同 token。平均内容差分能量份额为 0.2906/0.2947，procedure 覆盖比例为 38.6%/30.7%。因此“固定预算、平均能量接近”成立，“只改变连续性、其他完全相同”不成立。当前证据不能区分连续性、程序步骤完整性和语义覆盖。

**不确定性应按任务组处理。** 题目共享 calculator，不能把所有题视为独立。已有按 calculator 重采样的恢复差 95% CI（置信区间，用组级重采样估计不确定性）约为 [0.09, 0.48]；比只报题级检验更合适，但仅 14 组仍需逐组稳健性分析。

**另一处边界：输出格式不是纯长度控制。** 同批题的末位置最佳替换恢复 1.000 / 0.235 / 0.003，分别对应单 token 选择、短数值和逐步推理。改变格式也改变计算要求，不能将差异全部归于生成长度。

# 2　最近邻：从任务向量到分布式表示

## ① In-Context Learning Creates Task Vectors
Hendel et al.｜Findings EMNLP 2023｜arXiv:2310.15916 [R2]

**研究对象与实验。** LLaMA、GPT-J、Pythia；算法、翻译、语言和知识类共 18 个任务，主实验限制单 token 输出。先输入 few-shot（少样本示例）和 dummy query（与目标题不同的占位问题），提取末尾箭头 token 的中间层状态；再把它替换到没有示例的新问题的同层末位置。

**贡献与关系。** 证明某些任务可以用一个自然形成的状态向量转移。dummy query 是防止搬运目标题答案的重要设计。它是我们 last-token replacement 的直接先例；我们的长程序与自由推理是对象扩展，不能仅据此否定其短答案结论。

## ② Function Vectors in Large Language Models
Todd et al.｜ICLR 2024｜arXiv:2310.15213 [R3]

**研究对象与实验。** GPT-J、GPT-NeoX、Llama 2 等；反义词、大小写、国家首都、翻译等任务。把正确示例的平均 attention-head 输出移植到标签被打乱的运行，用正确答案概率的改善筛选关键 heads；聚合成 Function Vector，再加到新 prompt 末位置的 residual stream（逐层更新的主隐藏状态）。

**贡献与关系。** 不只是“抽取最后一个隐藏向量”，而是先因果筛选组件，再跨 prompts 聚合；测试跨问题转移，也有自然文本生成扩展。整 residual 替换失败不等于这套 FV 方法失败。若要把单向量作为被否定的基线，应补真正的提取和验证协议。

## ③ Just-in-time and distributed task representations in language models
Li et al.｜arXiv:2509.04466，核查 v3 [R4]

**研究对象与实验。** Gemma 3 为主，附加 Qwen 3；任务包含重复输出、列表变换和不同语义子任务。对模板中的多个位置做状态移植，并用 linear probe（学习线性分类器，检验状态是否可解码出任务身份）比较“能读出任务”和“能让模型执行任务”。

**贡献与关系。** 可解码不等于可转移；表示的可用性有 token 时间局部性和语义范围。v3 也显示部分单向量能支持长输出，因此不能简化为“长度越长必然失败”。这是我们“单位置不足、长过程分布式计算”叙事最直接的近邻之一。

## ④ Where does In-context Learning Happen in Large Language Models?
Sia et al.｜NeurIPS 2024｜arXiv:2403.04510 [R5]

**研究对象与实验。** 多种开放模型的机器翻译和代码生成。分别从某一层开始屏蔽示例、指令或问题的 attention，比较生成质量，并研究单层屏蔽和 head 控制。

**贡献与关系。** 测量模型在什么深度之后不再需要读取 context，且边界依赖任务和模型。我们的累计 attention knockout 有明确先例；新增应强调：与同设置的 span transfer 配对后，两种边界如何分离，以及为什么分离。

# 3　最近邻：指令位置、交互与持续注入

## ⑤ Where does an LLM begin computing an instruction?
Pola & Balasubramanian｜2025 workshop extended abstract｜arXiv:2511.10694 [R6]

**研究对象与实验。** Llama 3.2 1B/3B、Llama 3.1 8B instruct；键值、引文归属、字母选择及两步组合。保持内容和输出形式，构造最小指令差异；分别移植指令关键词、内容控制位置和 prompt 最后位置，扫描层数，测答案翻转率。

**贡献与关系。** 直接研究源指令位置与最终输出位置在不同深度的作用，是 span/last 比较的近邻。但晚层指令 patch 失效本身并不能证明“不再读取指令”；我们配对读取敲除可以检验这一推论边界，不能在未复现其设置前直接声称反驳该论文。

## ⑥ Patches of Nonlinearity: Instruction Vectors in Large Language Models
Bigoulaeva et al.｜ACL 2026｜arXiv:2602.07930v2 [R7]

**研究对象与实验。** OLMo-2 1B/7B 的 base、SFT（监督微调）和 DPO（偏好优化）阶段；词形/反义词、动物属性及四个 BigBench 任务。将完整指令的末 token 状态，移植到 query 前的 filler token；比较一层及多层 patch，测答案排名和分数，再分析局部计算路径。

**贡献与关系。** 指令表示可以在 query 前形成；多层作用可超加性，即联合效果大于单独效果之和。这直接提醒我们：单次失败可能是组件交互问题；还应测试 skill-last，而非只有 prompt-last。其对象主要是短指令/答案，不等于已经解释长程序执行。

## ⑦ Do different prompting methods yield a common task representation in language models?
Davidson et al.｜arXiv:2505.12075，核查 v3 [R8]

**研究对象与实验。** 比较同类任务由自然语言指令和示例触发的 FV；从末位置的 head 输出提取表示，用无关文本、其他任务指令等作控制，比较转移作用和关键 heads。

**贡献与关系。** 指令与示例使用部分不同的组件，组合可互补。因此“从示例扩展到 instruction/skill”本身已经不够新。我们 procedure 与 example 的比较，应进一步解释程序内容、例子和格式各自控制了什么计算。

## ⑧ Improving Instruction-Following in Language Models through Activation Steering
Stolfo et al.｜ICLR 2025｜arXiv:2410.12877 [R9]

**研究对象与实验。** Phi-3、Gemma 2、Mistral 等；格式、长度、包含/排除词语等指令，包含 IFEval 评测。由同题有/无指令的末 token 差分均值提取方向，再在某层所有 token 位置施加 steering（激活加法干预），控制持续生成。

**贡献与关系。** 抽取位置不等于施加位置。我们只在 prefill（整段 prompt 的首次前向计算）注入一次，不能据此排除持续注入的单向量方案。另一方面，约束输出风格成功，也不等于可携带新的多步计算程序。

**跨论文比较的关键。** 必须对齐四个维度：示例/短指令/长程序；同题/跨题 donor；单次/持续干预；下一 token 分数/完整任务成功率。只按“也用了向量”归类会掩盖真正差异。

# 4　last-token 注入是否合理

**合理，而且有直接先例；但它只检验一个候选通道。** 在 causal Transformer 中，prompt 最后位置能访问所有前文，其最终状态用于预测下一 token。因此它适合检测任务选择或答案准备，却不保证存储整份可独立执行的程序。Hendel、Todd 的工作是明确先例。[R2–R3]

**必须区分三个位置。** prompt-last 是问题之后、生成开始之前的最后位置；skill-last 是程序文档末尾，通常位于 query 之前；生成轨迹的 last token 又是另一个对象。前两者可见的信息不同；Instruction Vectors 的核心位置是 skill/instruction-last，而不是我们目前的 prompt-last。[R7]

**同题、最终层替换有答案搬运风险。** 如果 donor/receiver 使用同一个问题，将最终层最后位置的整个 residual 替换后，下一 token 的分布也随之复制。对单 token 选择题，这可能近乎直接复制答案决策。这样的高恢复率不能单独证明 query-independent（不依赖具体问题）的 skill。

**一次性与持续性要分开。** 本项目的白盒 hook 在首次 forward 生效，之后移除，正常自回归生成。持续 steering 会反复给每个生成位置施加方向，干预预算和作用方式都不同。比较两者有科学价值，但不能把持续干预的更多作用次数隐去。[R9]

**建议的最小公平比较。** 在相同题目划分下，比较 prompt-last、skill-last、procedure 末尾、原位 span，以及按原方法提取的跨题 TV/FV。再对同一方向比较 prefill 一次与逐生成 token 注入。层数和强度只在独立开发集选择，测试阶段固定。

**防止误读负结果。** 单位置失败至少有四种解释：载体容量不足；抽取位置错误；干预时机不合适；receiver 其他状态与新表示不兼容。只有当前实验无法区分这些解释时，就不应写成“skill 不可压缩成一个向量”。训练得到的 gist/memory token 又属于另一类压缩方法，不能被原生状态移植的失败排除。

**一个有辨识力的实验。** 对同一程序，用不同问题提取 donor，再在新题测试；保持相同答案语义、改变编码长度，避免同时改变求解步骤。若同题末层有效、跨题无效，而早中层跨题有效，可以区分答案决策搬运与任务级迁移。若长输出只有持续注入有效，解释应转向干预时机，而非单向量的绝对容量。

**方法术语。** activation patching 是用另一运行的隐藏状态替换或调整目标状态，观察行为变化；ablation 是移除组件或连接，观察性能下降。前者测特定接收状态下的恢复，后者测特定破坏方式下的依赖。两者都比热图更有因果辨识力，但都依赖干预设计，不能自动等同“找到了模型原生算法”。

# 5　能否结合 Recursive Self-Improvement

**可以，但应研究新的对象。** 现稿是冻结模型在一次任务中的程序使用；RSI 是系统让改进结果被后续轮次继承。更强的主张还需证明“改进过程本身变得更有效”。基础模型权重不变，并不排除系统级 RSI；但一次 forward 的层数不是递归改进轮数。

**最近的系统工作已覆盖很多直觉。** ACE 用生成、反思和整理维护增量 playbook，GEPA 根据执行反馈演化 prompt；HyperAgents 允许修改 task agent 和 meta agent，并有固定 meta-agent 对照。它们提供实验载体，但不直接解释 skill 文本在神经内部怎样改变改进过程。[R10–R12]

**不能把“新 skill 有用吗”当作全新问题。** Coalition-Aware Skill Reliability 已研究技能库组合、边际效用和跨域负迁移，主要在技能库层做干预。我们若只移除技能、看任务分数，重叠很大。[R13]

**最新 RSI 结果也需克制。** AIDE² 的 Recursive self-improvement of AI research agents 报告多轮 agent 改进，但作者对外层改进角色相较强基线的优势仍保留不确定性。任务执行更好，不自动等于生成下一代改进的能力更强。[R14]

## 值得单独立项：内部干预能否改变“后代质量”

**科学问题。** 一个 meta-skill 指导如何诊断失败、设计验证和修订下游技能。它的更新究竟只改变当前回答风格，还是改变产生更好技能的计算过程？能否把新版本的局部内部状态移植给旧版本，使其产出更有效的后代 skill？这是候选方向，不是已证明的创新。

**最小两阶段实验。** 第一阶段固定开放模型、失败轨迹和总预算，比较旧/新 meta-skill、新→旧 patch、旧→新 patch、等长无关更新和文本关键句消融，保存生成的 candidate skill。第二阶段用全新进程、固定 executor 和独立隐藏任务评估这些候选；只允许指定 skill 文件跨阶段保留，避免答案和轨迹泄漏。

**读数与真正递归。** 测相同预算下的隐藏测试增益、有效改进概率和旧能力保持率。若这一阶段稳定成立，再比较固定 improver、只更新 task-skill、同时更新 meta-skill 的多条独立演化链。不能以被干预模型自己的评分证明改进成功。

**可能的强结果。** meta-skill 某程序部分的双向干预，能改变下一代在未见任务家族上的收益，且文本消融无法给出同样的计算解释。本轮检索未见近邻完成同一“两阶段内部干预→独立后代质量”实验；这不是穷尽性首创保证。

**停止条件。** 若新版本无跨家族增益、patch 只改格式、依赖同题 donor，或文本消融已解释全部，就不要继续堆昂贵白盒实验。也不要把高 rank 或高恢复率直接当作 RSI reward：它们尚未被证明与真实改进质量单调对应。

# 6　下一步与一手参考文献

**最值得优先补的实验：接收态交互四格。** 同一层比较：错误运行、只换 skill span、只换预先指定的 query 状态、两者都换。加反向 patch、同运行替换和多个错误接收方。若晚层只有联合替换恢复，且不是 query 单独搬答案，才支持兼容性解释；随后定位具体 head/读取路径。query 范围应在独立开发集确定，避开直接输出瓶颈。

**第二优先：控制程序内容再谈连续性。** 固定 token 预算，匹配 procedure/example/定义覆盖、位置区间及能量分布，多种子比较完整步骤和切碎步骤。能量归一化本身会改变干预剂量，需保留原剂量对照。若匹配后效应消失，应诚实将结论转向语义单元覆盖。

**投稿判断如何更新。** 如果上述实验形成可复现、能预测新条件的机制结论，并补齐 TV/FV、skill-last 等公平对照，我会显著上调对 A 类会议竞争力的判断。若只能保留“span 好、last 差”的现象组合，近邻重叠仍是主要拒稿风险。WWW 还需额外解决范围适配；增加实验数量不能替代这一点。
