# 论文主线与改写说明

日期：2026-10-14 开始，2026-10-15 完成。基于当前本地实验记录重构，不新增模型实验。

## 一句话主线

**skill 状态在中间层已经难以转移，但模型仍依赖读取这些源位置。状态可转移性与源依赖性是两个不同的行为属性，不能用一个替代另一个。**

标题改为 *When Skill Transfer Fails but Reading Continues*，直接呈现需要解释的现象。

“paradox”是解释上的表面矛盾，不是逻辑悖论；关键实验解决“转移失效是否意味着源不再必要”的疑问，没有识别全部内部机制。

## 1. Introduction：五段 + 三项贡献

| 段落 | 功能 | 具体内容 |
|---|---|---|
| 第一段 | 问题与 Web 联系 | Web 检索将程序性文档交给 LLM；公式、条件与步骤需要在回答过程中持续可用。问题是文档内部状态何时能替代文档，何时仍需保留源访问。 |
| 第二段 | 观测到的 paradox | early span transfer 有效，但 Qwen3-8B/MedCalc 的恢复比例从 L12 的 0.74 降到 L13 的 0.16。模型已用完程序，还是 receiver 无法使用它？ |
| 第三段 | 关键实验 | 分别移植 correct-skill 状态到 wrong-skill receiver，以及在 correct-skill run 中阻断后续源注意力；前者测试转移，后者测试源依赖。先用 early span 的 0.89 恢复验证 probe 有效。 |
| 第四段 | 核心 discovery | transfer 的首次半幅边界为 L13，reading 的首次半幅边界为 L25；中间区间的源仍有用，但状态不易在 receiver 中复用。不能把 transfer failure 当作已经不需要 source。 |
| 第五段 | 进一步验证 | 六个模型×任务组合复现边界顺序；重复晚层替换不能恢复早层效果；内容、位置、跨题共享与 rank 控制约束解释。随后列三项贡献。 |

三项贡献分别是：

1. **区分 transfer 与 reading 的互补干预测试及深度间隙发现**。
2. **经过内容、位置和跨题控制验证的程序表示 probe**。
3. **跨模型/任务、rank 与重复替换提供的适用范围和解释边界**。

这里的 recovery ρ 是 `(干预准确率 − receiver 准确率)/(donor 准确率 − receiver 准确率)`；1 表示恢复全部 donor 增益，0 表示没有恢复。reading 指标 q 是阻断后在其 eligible rescued items 中仍正确的比例；低值表示后续源访问重要。两者分母和运行背景不同。

## 2. Related Work

围绕四个比较面展开：已有 task/function/instruction vector 的转移与 source masking；不同 patch 实际读出什么；skill 与 compact context 表示；rank 和谱诊断。保留与最近邻的具体差异，不把单独的末位置 patch、span patch 或注意力敲除声称为首创。

Web 动机引用：Tan et al., *HtmlRAG: HTML is Better Than Plain Text for Modeling Retrieved Knowledge in RAG Systems*, WWW 2025，arXiv:2411.02959，DOI:10.1145/3696410.3714546。其结论是保留/处理 HTML 结构可改善检索知识建模；与本稿关系是说明“文档表示方式影响 reader”这一动机，不能作为本稿已经验证 Web 系统收益的证据。

一手来源：[arXiv](https://arxiv.org/abs/2411.02959)、[作者代码与论文元数据](https://github.com/plageon/HtmlRAG)。本轮复核作者公开记录；既有近邻调研见 `audit/RESEARCH-context-lasttoken-rsi-20261003.md`。

## 3. Problem Formulation

定义 correct/wrong/no skill、matched content difference、span replacement、恢复比例 ρ、receiver 筛选与 reading knockout 的 q。阈值是两条曲线的操作性摘要，不是统一的信息量度量。最后定义中心化 rank truncation，为后续结构控制服务。

## 4. Experiments：论证顺序

1. **Setup**：任务、模型、筛选、组级不确定性与 identity 校验。
2. **建立内容敏感的 probe**：分离内容与文档存在效应；答案格式揭示单位置 probe 的局限。
3. **在源位置恢复效果**：完整 span 及内容/排列/噪声控制，先证明实验工具确实能转移有效内容。
4. **立即回答核心问题**：深度曲线显示 transfer/reading 间隙；重复晚层替换不能弥合；谱下降不能直接解释为压缩。
5. **位置数量与放置方式**：数量本身不足；内容覆盖、块选取与位置对齐影响恢复，不能把这些混杂写成“纯连续性机制”。
6. **可复用内容而非特定答案**：跨题 donor、prompt 顺序与跨 skill mean 控制。
7. **rank 要求**：多个领先方向支持恢复；测得的 rank knee 是指定网格上的半幅摘要，不是最小充分秩。
8. **跨模型与任务复现**：六组边界与 early recovery，明确两类干预的样本差异；hidden width 不能单独解释 rank 要求。

## 5. Conclusion

先回答主问题，再说明对 representation 研究与 context reuse 评估的含义。实际 receiver 中能否恢复行为，以及去掉后续 source access 后是否仍能成功，需要分别验证。论文不把这项机制观察扩写成已经实现的压缩效率或多轮 Web agent 效益。

## 本轮纠正的事实与仍需补强之处

- L14 转移恢复仍为 0.16129；“不超过 0.07”的晚层区间应从 L15 开始（两位小数口径）。
- knockout 的 q(L25)=0.58209、q(L26)=0.45522、q(L27)=0.55970。首次 crossing 是 L25，不能声称 L25 以后单调过半。
- 六组 transfer/knockout 的 n 分别是 135/134、99/63、362/90、132/125、92/46、115/65。当前比较是同组筛选背景下不同 eligible 子集的曲线；严格共同 item 的复核仍是优先补强项。
- 主因果结论对 baseline 筛选后的组成立；并非完整 benchmark 上的无条件效应。
- receiver 其余状态与注入状态如何交互仍未识别；目前能排除部分简单解释，不能声称完整机制已解决。
- 文档如何被 reader 保留和复用构成第一页的 Web 科学动机。WWW 2027 官方要求具体 Web 相关研究问题，仅提到 Web 名词或使用 Web artifact 不足以保证 scope。改写提高论证清晰度，不能保证录用。
