## 建议手动修改：保护标题专名的大小写

ACM BibTeX样式会将未加保护的标题转为sentence case，当前PDF中可见Qwen3、SkillsBench等专名被转为小写。这不影响引用编号，但应修正。只改对应条目的title字段；不要改citation key。

| 条目及快照行号 | 当前title中的片段 | 手动替换为 |
|---|---|---|
| `yang2025qwen3`，257 | `Qwen3` | `{Qwen3}` |
| `skillsbench2026`，82 | `SkillsBench` | `{SkillsBench}` |
| `sweskills2026`，96 | `SWE-Skills-Bench` | `{SWE-Skills-Bench}` |
| `doc2lora2026`，184 | `Doc-to-{L}o{RA}` | `{Doc-to-LoRA}` |
| `shazeer2019fast`，536 | `Transformer` | `{Transformer}` |
| `vaswani2017attention`，544 | `Attention Is All You Need` | `{Attention Is All You Need}`，如希望保留其原题大小写 |

例如：

```bibtex
title = {{Qwen3} Technical Report},
title = {{SkillsBench}: Benchmarking How Well Agent Skills Work Across Diverse Tasks},
title = {{SWE-Skills-Bench}: Do Agent Skills Actually Help in Real-World Software Engineering?},
title = {{Doc-to-LoRA}: Learning to Instantly Internalize Contexts},
```

上面四行分别放到四个对应条目内，不是放到同一个条目。普通标题单词不必全部强制大写。

## 投稿版首页：建议调整，但不标作官方硬性违规

`main.tex:24` 当前是 `\setcopyright{acmlicensed}`，第32行是 `\settopmatter{printacmref=true}`。因此第1页显示正式ACM版权许可文字与ACM Reference Format，含“2027 Copyright held by the owner/author(s). Publication rights licensed to ACM”。这些内容在匿名审稿稿件中没有必要。

若这是匿名投稿版，建议手动替换为：

```latex
\setcopyright{none}
\settopmatter{printacmref=false}
```

其他 `anonymous, review` 参数保持不变；不要填作者真实姓名，也不要虚构DOI/ISBN。这项会释放首页空间，但可能改变后续浮动体位置，必须重新检查全文12页限制。

官方CFP明确要求匿名与指定版式，但没有明确写必须隐藏上述两块，因此不能声称现状必然违反WWW规则。录用后的camera-ready版权设置应以ACM下发信息为准。
