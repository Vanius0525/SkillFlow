## 3. 四条层扫描：全部读不出东西，而且原因是可预料的

```
e2-tierB-const  n=40  层 0..34 步长 2   分母 mean_logprob_delta = 0.512
   recovery_real   0.015 0.020 0.270 0.434 0.476 0.742 0.754 0.745 0.707 0.615
                   0.543 0.771 1.236 1.183 1.160 1.146 1.131 1.134
   best_layer 24   best_recovery 1.236   CI95 [-4.404, +5.255]      <-- 含 0
   同层 mismatched -25.41                                            <-- 前向被打坏

e2-tierB-proc   n=40  分母 mean_logprob_delta = 0.0858
   best_layer 12   best_recovery 4.768   CI95 [-14.613, +18.740]    <-- 含 0
   同层 mismatched 4.807   meanvec 4.754                             <-- 与处理组相同
   晚层 mismatched -175 到 -236                                      <-- 彻底崩

e1-tierB-const  best_layers 8-11  net +0.2685  CI95 [-0.190, +0.835]  <-- 含 0
e1-tierB-proc   best_layers 8-11  net +0.2770  CI95 [-0.256, +0.840]  <-- 含 0
```

**判断：**

1. **每一个区间都含 0。** 没有一条曲线支持任何数值结论。
2. **根因是分母，不是噪声。** recovery 是「补丁挪动了多少」除以「skill 本身挪动了多少」。
   Tier B 上后者是 **+0.512 nats（const）和 +0.0858 nats（proc）**。
   除以 0.0858 之后，`e2-tierB-proc` 的 recovery「峰值」是 4.768 ——
   一个比 1 大得多的数，看着像超额恢复，实际是**除以近零**。
   `e2_patch.py` 的 `--gate-unconfirmed` 横幅说的就是这件事，现在有了实测的例子。
3. **`e2-tierB-proc` 的最强反证：峰值层上 real 4.768、mismatched 4.807、meanvec 4.754。**
   三者相同 —— 补丁搬过去的东西**完全不带逐题信息**。
   对比 Tier A 层 21 的 real 0.923 / mismatched 0.308 / filler 0.000。
4. **8B 的晚层比 1.7B 脆得多**：mismatched 到 −25（const）和 −236（proc）。
   Tier A 的「打坏区间」在 8B 上是同一个现象的放大版。

**所以：Tier B 的层扫描不是「跑了没有结论」，是「这批题上恢复率这个量没有定义」。**
要修的是题集（把基线从 0.819 拉到 0.4–0.7），不是干预方式。§15.6 已经写了怎么修。

## 4. e7：两份内容互斥的 skill，方向余弦 0.97；一份无关文档，0.94–0.96

这次**带中性对照**（§12.3i 那次没有，是当时最大的疑点）：

```
  cos(constants, procedure)      max 0.9716 @ L10   CI95 [0.9712, 0.9719]
  cos(constants, filler-neutral) max 0.9445 @ L10   CI95 [0.9440, 0.9450]
  cos(procedure, filler-neutral) max 0.9555 @ L10   CI95 [0.9550, 0.9559]
```

**判断：** 两份**内容互斥**的 skill 之间是 0.972，各自与一份**无关**文档之间是 0.944–0.956。
**几乎一样近。** §12.3i 的 0.97 因此**不是「两份 skill 共享一个签名」的证据** ——
它就是「上下文里多了一份长文档」的签名，Tier A 上量到 0.947，Tier B 上量到 0.944–0.956，
**两个梯队、两个模型、两套题，同一个数量级。**

CI 极窄（宽度 0.001），所以论文里那句 "as close as they are to each other" **可以写**，
而且现在两个梯队都有。

**这一条和 E11 合起来才完整**：几何上内容成分**很小**（余弦 0.97 vs 0.95，差 0.02），
而 E11 的减法证明**恰恰是这个小成分在承担行为**（差向量修回 10/13，被减掉的通用成分修 0/13）。
单看几何会得出「注入没有内容特异性」的错误结论。
