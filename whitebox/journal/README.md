# journal — 每次实跑的原始输出和当时的判断

一次跑一个文件，命名 `YYYY-MM-DD-<跑了什么>.md`。

## 为什么和 HANDOFF 分开

`HANDOFF-whitebox.md` 记的是**结论现在是什么**，会被后来的跑覆盖重写。这里记的是
**那一次到底打印了什么**，写完不再改。两者的区别在下面这种时候才显出来：

- §12.3c 判断层 27 是退化的，靠的是 `mismatched` 那一列的 `+0.799`。那个数字不在
  任何一份 summary 的结论里，它只出现在当时的终端输出中。
- §12.3g 判断 E6 多半是抽取坏了而不是 H5，靠的是 near 和 **far 两个口味给出逐字节
  相同的分布**。任何一次单独的跑都看不出这一点。

**结论会被修正，而修正需要原始数字还在。** 一个只保留最新结论的文档回答不了"上次
那个判断是基于什么"，而那恰恰是发现自己错了的唯一途径。

## 一个文件里放什么

1. **命令和 run id** —— 别人要重现的入口
2. **原样贴的终端输出** —— 不要摘要、不要重排，包括看不懂的告警
3. **当时的判断，以及它依赖哪个数字** —— 把"我认为 X"和"因为打印了 Y"分开写
4. **当时不确定的事** —— 这一条最容易漏，也最有价值：它是下一次该查什么的清单
