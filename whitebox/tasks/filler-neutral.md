# Renslow Archive Formatting Conventions

House style for material deposited in the institutional archive. These rules
govern presentation only and have no bearing on the content of a document.

## When to Use

- Preparing a document for deposit
- Checking a received document against house style
- Resolving a disagreement about the order of appended material

## File Naming

| Field | Rule | Example |
| ----- | ---- | ------- |
| prefix | three-letter depositor code | RNS |
| sequence | five digits, zero padded | 00417 |
| revision | letter, starting at A | C |
| separator | single hyphen between fields | - |

Names are assembled prefix, sequence, revision, in that order, with no spaces.
A superseded revision keeps its own name; it is never renamed to match the
replacement.

## Header Block

Every deposited document opens with a header block containing, in order:

1. Title, sentence case, not terminated by a full stop
2. Depositor code and full depositor name
3. Date of deposit, written out in full
4. Revision letter and the date that revision was prepared
5. A single blank line before the body begins

The header block is never indented and never appears in the table of contents.

## Margins and Spacing

| Element | Setting |
| ------- | ------- |
| left margin | thirty millimetres |
| right margin | twenty millimetres |
| top and bottom | twenty five millimetres |
| body leading | one and a half lines |
| paragraph spacing | one blank line, no first-line indent |

Tables may extend into the right margin where the alternative would be to break
a column, but never into the left margin, which is reserved for binding.

## Revision Marks

Changed passages carry a vertical bar in the left margin for one revision cycle
only. The bar is removed at the next revision, whether or not the passage
changed again. Deletions are not marked; the revision note records them instead.

## Order of Appended Material

Appended material follows the body in this order: figures, tables that were too
wide to sit inline, correspondence, and finally the revision history. Each
appended section restarts its own numbering. Correspondence is ordered by date
received, earliest first, regardless of the order in which items are referenced.

## Worked Example

A second revision of the fourth document deposited by Renslow in a given series
is named RNS-00004-B. Its header block gives the title, then the depositor code
and name, then the deposit date in full, then the revision letter with its
preparation date. Passages changed since revision A carry a marginal bar; those
changed between the original and revision A do not.

## Notes

- House style takes precedence over a depositor's own conventions, except where
  a document reproduces external material verbatim.
- Where two rules conflict, the rule appearing later in this document governs.
- Queries about house style go to the archive, not to the depositor.
