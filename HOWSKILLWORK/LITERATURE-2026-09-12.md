# 文献调研（2026-09-12）—— 与本文主张的关系，逐条

调研方式：WebSearch + WebFetch 读原文。每条给：**出处 → 它主张什么 → 与我们的关系 → 我们必须怎么改**。

---

## A. 最接近、且必须显著引用的：单向量不够，已经有人从另一个角度证明过

**Dong et al., *Understanding Task Vectors in In-Context Learning: Emergence,
Functionality, and Limitations*, arXiv:2506.09048（ICLR 2026）**

- **主张**：在线性 transformer 里，注入一个 task vector 在功能上等价于一个 **rank-one 映射**。
  Proposition 4：`存在 rank-one 的 W 使 y=Wx 且 x=Wy` ⟺ `x=y 或 x=−y`。
  所以**需要高秩映射或双射的任务，单个 task vector 原则上表达不了**。
  在 Llama-7B/13B 上用显著性分析做了经验验证。
- **修法**：TaskV-M——从 N+1 条不同的 ICL prompt 生成 N+1 个向量，
  替换 few-shot prompt 里**所有箭头 token** 的 embedding，而不只是最后一个。
- **任务**：线性回归（合成）、翻译单词、词形变换、大小写转换、反义词——**答案都是单/少 token**。
- **注入位置**：箭头 token（`→`）。

**与我们的关系——这是最重要的一条，有一处直接对接：**

> 我们 Tier A 上 `add_dbar`（全集共用一个向量）只有 **0.062**，而 39 行的换算表正是一个高秩查找。
> **他们的定理预测了这个失败。** 也就是说，我们的一个零结果有独立的理论解释，应当明说。

**但两者限制的是不同的轴，不能混为一谈：**

| | 他们 | 我们 |
|---|---|---|
| 受限的是什么 | **任务映射 W 的秩**（能不能表达这个 input→output 关系） | **答案占多少 token**（一个位置能搬走多大的决策） |
| 证据 | 线性 transformer 的理论 + 显著性 | 同模型同题**只换答案格式**：1.00 / 0.30 / 0.00 |
| 反例检验 | —— | Tier A 选择题的映射是 39 行查找（他们意义下高秩），**而单位置补丁 `add_d_i` 仍然 0.812**——因为答案只有一个 token。两个限制是正交的 |
| 修法 | 在 few-shot 的多个箭头位置注入多个向量 | 在**文档自己的 token span** 上注入（m 个位置） |

**必须改**：正文和 Related Work 都要明确写「单向量不够」不是我们首先提出的，
并把 `dbar` 的零结果归因到他们的定理。我们的 delta 是**答案长度这条轴**和**文档 span 这条通道**。

## B. 一条看起来像反例、实际上是我们最强佐证的

**《When Chain-of-Thought Fails, the Solution Hides in the Hidden States》, arXiv:2604.23351**

- **主张**：把模型**自己生成的 CoT 序列**中某个 token 的隐状态，补进一条
  direct-answer prompt 的最后一个位置，GSM8K 上恢复率 **≥99%**，
  即使原来的 CoT 推错了也能恢复。
- **供体**：`generated CoT sequence` 上的状态——**模型已经推理完之后**。

**与我们的关系：**

> 同一个位置、同一种补丁。**供体取自「已经算完」时，单位置搬得动（≥99%）；
> 供体取自「还没开始生成」的 prompt 时，搬不动（我们 0.000）。**
> 这正好证明那个位置装的是**决策/答案**，而不是文档的内容。

**必须改**：把它写进正文作为正面引用，而不是回避。它是我们「最后一个位置携带的是决策」
这个论断的独立佐证，而且比我们自己的证据更直接。

## C. 已经有人说过「单个静态位置不足以刻画 CoT」

**《Mechanistic Interpretability of Chain-of-Thought Reasoning via Sequential
Activation Patching》, arXiv:2608.22332**

- 原文动机里直接写：`standard activation patching at a single static token position
  is insufficient to characterize these temporally distributed effects`，
  提出 sequential activation patching（跨 token 位置追踪并聚合）。

**与我们的关系**：他们把这件事当作**动机断言**，我们把它当作**被测量的量**——
用同模型同题只换答案格式，给出 1.00 / 0.30 / 0.00 的受控阶梯，并给出 k=1/4/16 的容量曲线。
**必须改**：不能写成「我们首次指出」。要写成「这一点被断言过；我们把它变成一个受控测量」。

## D. 深度：也有人做过

**《Where does an LLM begin computing an instruction?》, arXiv:2511.10694**

- 对 instruction 的 token 位置跨层做 activation patching，结论是
  instruction 在**中间层之后就不再被需要**。

**与我们的关系**：我们的「单层交接在 L15 死掉」不是独立的新发现。
**我们仍然独有的是三件事**：
1. **充分性与必要性给出不同深度**（移植 L15 死，而只屏蔽最后 6/36 层仍损失 0.50→0.30）；
2. 答案长度作为控制变量；
3. **秩塌缩的对应 + 一个被验证的可证伪预测**（doc-last 下 PR 不塌缩，L16 从 0.14 升到 0.80）。

**必须改**：Related Work 要点名这篇，并把我们的差异写成上面三条。

**《Controllable Context Sensitivity》, ICLR 2025** —— context vs 先验知识的可控性。
与我们发现的「模型本来就会做这个 calculator」混淆直接相关，应引用。

## E. 可靠性一侧的旁证

**《Steering off Course: Reliability Challenges in Steering Language Models》, arXiv:2504.04635**

- function vector 用默认超参只在 **20%** 的 model×task 组合上恢复 5-shot 性能；
  即使全超参搜索，也只有 **76%** 的组合达到 5-shot 的一半。

**与我们的关系**：独立的可靠性批评，与我们的负结果同向但机制不同（他们是超参敏感，我们是答案长度）。
引用为 convergent evidence。

## F. 选择题这条陷阱，有现成的机制解释

**Wiegreffe et al., *Answer, Assemble, Ace*, arXiv:2407.15018（ICLR 2025）**

- 选择题里「选哪个字母」这个决定**因果上归于单个中间层**及其少数几个注意力头
  （每层 1–4 个头），中间 1–3 层选定答案符号，末几层放大它的概率。

**与我们的关系**：这正好解释了**为什么选择题上单位置补丁能到 1.000**——
决策本来就被压缩进一个位置的一个符号。
**必须改**：我们的 §「选择题制造地板」应当引用它作为机制说明，而不是只给现象。

## G. 调研没有覆盖到的（诚实标注）

  **但这是"没搜到"，不是"不存在"。** 投稿前应当再做一轮更系统的检索

## H. 结论：我们的 delta 在调研之后剩下什么

**不再声称为新的：**
- 「一个向量不够」（Dong et al. 从秩的角度证明过）
- 「单个静态位置不足以刻画 CoT」（2608.22332 断言过）
- 「instruction 在中间层之后不再被需要」（2511.10694）
- 「选择题把决策压进一个位置」（Wiegreffe et al.）

**仍然是我们的：**
1. **答案长度作为容量变量的受控测量**（同模型同题只换格式：1.00 / 0.30 / 0.00），
   以及它与 Dong et al. 的**秩限制是两条正交的轴**（Tier A 选择题给出反例）。
2. **文档自己的 span 这条通道**，以及 `h_recv + d = h_gold` 这个恒等式——
   它让「移植」在数学上**就是** α=1 的内容注入，从而把整套向量实验搬到真实文档上。
3. **真实 skill 上的完整因果臂 + 配对对照**：剂量阶跃（α=0.5→0.6）、
   近亲/远亲都不迁移、乱序失效、范数无关（1.76×→1.00× 无变化）。
4. **向量的成分**：58% 的能量是共同偏移而承载零；doc-first 下 `d` 跨题**逐位相同**（可证），
   doc-last 下换题向量仍然 +1.06 而题目专属分量在任何深度都是 ~0。
5. **文档内部的干预式定位**（prompt 一个 token 不动，Q2 = 公式正文承载 0.80）。
6. **秩↔深度的对应 + 一个被验证的可证伪预测**。
7. **两个方法学陷阱**：错误文档对照的强度取决于它像不像；
   以及「模型本来就会做这道题」会把跨技能臂污染成假的部分迁移（那半边上纯噪声都有 +0.14）。

## I. 看起来像反例、读完变成佐证：把 prompt 压进**一个**向量，掉不到 2%

**Ardoin, Einsele, Bregu, Wunder, *Prompt Compression via Activation Aggregation*,
arXiv:2607.08399（2026-07-09，FU Berlin）**

- **做法**：在中间层（Llama3.1-8B 的 **L12**）取整条 prompt 的激活，用一个学出来的
  **加权和**压成**一个**向量 `v`，注入到**早层（L2）**一个占位 token（U+FFFD）的位置上。
  权重由一个 4 层 MLP（隐层 2048/1024/512/256）给出，在 8 个任务族上用交叉熵训。
- **结果**：8 个玩具任务 **85.35% vs 全 prompt 86.92%**（差 1.57pp）；
  ARC-Easy 上 **77%**，masked-prompt 下界 32–34%。
- 附录还有「**一个向量同时编码 9 个任务**且不掉点」。

**为什么这不是反例，而且是我们最有力的外部佐证之一——两个理由，都要写进 Related Work：**

1. **他们所有成功的任务，答案都是短的。**
   玩具任务是 capitals / ISO 代码 / 大洲 / 年份 / 单词翻译 / 反义词 / 货币代码——
   全是单词级 exact-match；ARC-Easy 是 **A/B/C/D 单字母**。
   这正是我们说「一个位置能搬走多大的决策由答案长度决定」所预测的**能成功的那一半**。
   而且 ARC-Easy 是选择题——按 Wiegreffe et al. 的机制，决策本来就被压进一个位置的一个符号。
   **我们论文里已经有这一半的复现**：Tier A 选择题上单位置补丁 `add_d_i`=0.812。
   我们要写的是：**同一个模型、同一批题，只把答案格式从单 token 换成自由生成，
   同样的单位置补丁从 1.00 掉到 0.00。** 他们测了容易的那一格，我们把格子填满了。

2. **他们的最优配置是「中层取、早层注」，而且给的理由和我们的深度结论同构**：
   「injecting the compressed representation earlier leaves more transformer layers
   for it to be processed and integrated before prediction」。
   这是**另一组人、另一套方法（学出来的压缩器）独立得到的「浅层交接才行」**。
   我们的 L15 悬崖因此不是孤证。

**必须改**：Related Work 增加一段，标题就叫「一个向量什么时候够」。
把 Dong et al.（理论：rank-one 映射）、Ardoin et al.（经验：短答案 <2% 掉点）、
Wiegreffe et al.（机制：选择题压进一个符号）三条并排，
然后给出统一句：**单个向量是一个「选择器」，不是「内容的载体」。**
它能在模型已有的若干行为之间做选择（9 个任务 ≈ 3.2 bit），
但搬不动一份需要约 100 个方向才能重建的新文档。
—— 这句话可以做全文的统一论断。

## J. 「秩」这个词现在有三种，必须在正文里划清

搜「effective rank / participation ratio / residual stream」出来两篇 2026 的论文，
它们讲的**不是我们讲的那个秩**，但 reviewer 一定会混。

**J1. *Causal Dimensionality of Transformer Representations*, arXiv:2605.08740**

- 定义 κ(L) = eff-rank of `E_x[J_L(x)^T J_L(x)]`，即**该层的雅可比外积的有效秩**：
  「这一层有多少个方向在因果上影响输出」。用 attribution patching + SAE 宽度扫描估。
- 数字：Gemma-2-2B **L12（46% 深度）κ̂≈1990，κ/d=0.86，κ_PR≈280**。
- **关键两条**：
  (a) **κ 不随模型规模长**——Gemma-2-9B 的相对同深度层给出**一模一样的 N_causal=328**；
      作者称 κ 是「layer-intrinsic」、由任务多样性而非模型容量决定。
  (b) **κ 不随深度塌**——归因分数从早层到晚层掉 20×，但阈值校准之后**因果特征数不变**；
      他们明确说这纠正了之前用固定绝对阈值做跨层比较的研究。
- **他们明说没有做直接的秩截断**，用的是一阶代理。

**这对我们是好消息，而且给出了论文里最锋利的一句话：**

> **接收端的容量不随深度下降（κ 常数），下降的是消息本身的维度（PR(d) 64→17）。
> 交接窗口关掉，不是因为模型在深层装不下，而是因为文档的表示到那时已经被压成了摘要。
> 窄的是信道的发送端，不是接收端。**

而且它把我们的 `xfer`（把 L8 的高秩供体写进 L16）从「再做一个对照」
升级成**一个由外部文献支持的可证伪预测**：既然 L16 的接收容量没变小，
那么在 L16 供上高秩的消息就应该能救回来。成立即闭环；不成立则说明 κ 常数
这个说法在我们的设置下不成立，那本身也是一个值得报告的结果。

**J2. *Dynamics of the Transformer Residual Stream: Coupling Spectral Geometry to
Network Topology*, arXiv:2605.14258**

- 有效秩用熵定义 `erank = exp(-Σ p_i log p_i)`，p_i = σ_i²/Σσ_j²（**未中心化**）。
- Llama-3.1-8B：单层 ~436，**整条复合掉到 6.7（~65×）**；Gemma 4 E4B 掉到 5.9。
- 有因果干预：**Schur surgery**——把非正规分量 `N_ℓ` 按剂量 c 缩放，
  c=0 时有效秩回升 6.4×（Llama）。结论是塌缩来自训练出来的非正规结构。

**与我们的关系**：它量的是**复合映射（transfer operator）的秩**，
我们量的是**一份文档在自己 span 上的表示矩阵 d ∈ R^{m×d} 的秩**。
两者都叫 rank，对象完全不同。但它给了我们一条有用的外部事实：
**残差流的谱确实随深度收窄**，所以我们看到的 PR(d) 64→17 不是我们的度量的伪影。
注意它是未中心化的 erank，我们是中心化的 PR，要在脚注里说明差别
（未中心化时第一个奇异方向会被均值主导，这也是他们能掉到 6.7 而我们只掉到 17 的原因之一）。

**三种秩的对照表（要作为一个 table 放进 Related Work 或附录）：**

| | 秩的对象 | 谁 | 怎么测 | 是否直接干预 |
|---|---|---|---|---|
| 映射的秩 | 任务映射 `W`（input→output 关系） | Dong et al. 2026 | 线性 transformer 定理 + 显著性 | 否 |
| 雅可比的秩 | `E[J^T J]`（哪些方向因果影响输出） | 2605.08740 | attribution patching + SAE 宽度扫描 | **否（明说是一阶代理）** |
| 复合算子的秩 | 整条残差流的 transfer operator | 2605.14258 | 熵有效秩 + Schur surgery | 是（对非正规分量） |
| **表示的秩（我们）** | **一份文档在自己 span 上的 `d ∈ R^{m×d}`** | 本文 | **截断到秩 k 再注入，量行为** | **是（直接截断被注入的那个对象）** |

**我们是四者里唯一「把被注入的那个对象本身截断、然后量行为」的。** 这要明写。

## K. context distillation / doc→参数 这条线：不冲突，但要引

- **Doc-to-LoRA, arXiv:2602.15902**：hypernetwork 从文档 embedding 预测 LoRA 权重，
  让模型不带文档也能答该文档的问题（SQuAD / DROP / QASPER）。
  与我们正交：他们改**参数**，我们改**激活**；他们要训 hypernetwork，我们零训练。
  但它是「一份文档的作用可以被压缩」这个大命题的另一条路径，应当引。
- **Deep Context Distillation, arXiv:2503.08727**：在**输出空间和隐空间**双重蒸馏
  一个「看得见文档」的 teacher 到「看不见文档」的 student 的 knowledge module。
  它隐含承认「隐空间里有东西要搬」，与我们的 `d` 是同一个直觉，但走的是训练。
- **When Context Returns, arXiv:2606.11627**：on-policy context distillation 之后
  **把 context 放回去反而掉点**（context-induced degradation）。
  这条对我们是一个有趣的旁证：内化出来的东西和文档在上下文里时的作用**不是同一个东西**。
  我们的 `t = g + d` 分解正好给这个现象一个可测量的语言。

## L. 第二轮之后，delta 还剩什么（更新 §H）

**新增的「不再声称为新」：**
- 「一个向量可以承载一个 prompt」在**短答案**任务上成立（Ardoin et al. 2026，<2% 掉点）。
  我们必须**主动引用它**并说明我们的负结果不与它冲突——差别是答案长度。
- 「浅层注入优于深层注入」（Ardoin et al. 的 L12→L2 最优）。
- 「残差流的谱随深度收窄」（2605.14258）。

**第二轮之后仍然独有、而且被加强的：**
1. **答案长度这条轴**——现在有了明确的对照面：Ardoin 测了短的那一半，我们把长的那一半补上，
   并且是**同模型同题只换格式**的受控对照。
2. **文档自己的 span 这条通道 + 恒等式 `h_recv + d = h_gold`**（仍未找到先例）。
3. **直接截断被注入对象的秩**——上表显示四条秩的文献里只有我们这么做。
4. **「窄的是发送端不是接收端」**——由 2605.08740 的 κ 常数 + 我们的 PR 塌缩共同支撑，
   并由 `xfer` 直接检验。这是第二轮调研带来的**新论点**，之前没有。
