## 摘要（Abstract）

把一份短的技能文档——一段流程、一张查表、一道例题——放进语言模型的上下文，能稳定提高准确率。这份提升在模型内部发生在哪里，目前并不知道；而通常去找它的地方是空的：在 55 个第三方临床计算器技能上，写进提示末位置的每一个向量——包括直接整体替换该状态——都落在无文档基线上。只改变答案格式时，单位置补丁对一 token 答案恢复救回题的 1.000，对短数字恢复 0.30，在思维链下恢复 **0.000**：该位置携带的是模型的**决策（decision）**，而分布在几百个 token 上的决策装不进一个位置。

真正携带作用的通道是文档自己的 token 片段。由于长度匹配的接收方本身就持有一份文档，替换这段片段**就是**在 $m$ 个位置上以 $\alpha=1$ 注入内容成分——在 40 个计算器上它恢复了文档效应的 0.87，而半剂量、另一技能、打乱位置和噪声全部 ≤ 0.10。

在写入前截断被注入对象的秩，可以度量它有多大：秩 32 时 0.13，秩 128 时 0.77，被丢弃的底部 64 个方向什么也恢复不了。**在同一模型家族内**这个数不随宽度缩放（在窄四倍的模型上 $k^{*}=40$，宽模型为 52，预注册的「与宽度成比例」预测为 12），但它**不只是文档的性质**：同宽度的 Mistral-7B 需要 64–84。通道本身、它的各项对照，以及「文档能在哪一层被交接」与「文档在哪一层仍在被读取」之间的分离，在第二个任务领域和第二个模型家族上都复现。顺带我们撤回自己提出过的一个机制：片段参与比的「崩塌」其实是超大激活，而不是压缩。

## 1 引言（Introduction）

所谓「技能（skill）」，是一段放进模型上下文、让它能完成原本做不到的任务的短文档——一段流程、一个公式、一张查表、一道例题。已有一批基准测试文献度量它的效果，但没有一项度量说明文档在模型内部做了什么。

最自然的看法是比较有文档和无文档时的内部状态，而这种做法在其直观形式下行不通。在提示末位置，加入技能后残差流移动了很远——而在文档真正被读取的那些层里，把文档换成一份长度相同的无关文档，残差流移动的距离和方向几乎一模一样（第 0 到第 10 层余弦 0.91–0.95）。天真地读，这说明位移几乎不携带文档说了什么。对照行为就不能这样读：在 1,100 道配第三方技能的临床计算题上，金标技能比无文档高 +39.7pp，而长度匹配的**错误**技能是 −2.9pp [−8.8, +3.0]。行为全是内容；而在做读取的那些层上，几何几乎全是在场。

记 $h_{\text{no}}$、$h_{\text{wrong}}$、$h_{\text{skill}}$ 分别为无文档、长度匹配错误技能、金标技能下提示末位置的状态，则

$$\underbrace{h_{\text{skill}}-h_{\text{no}}}_{t\ \text{（总位移）}}=\underbrace{h_{\text{wrong}}-h_{\text{no}}}_{g\ \text{（在场）}}+\underbrace{h_{\text{skill}}-h_{\text{wrong}}}_{d\ \text{（内容）}}\qquad(1)$$

这是恒等式。我们把每个成分加回无文档状态、观察模型行为，来回答哪一边在起作用。

**该往哪里看，不该往哪里看。** 施加在**文档自身 token 以外**任何地方的补丁，搬运的是模型的**决策**而不是文档的内容；一个小的位置组能搬运多少决策，由答案占多少 token 决定（一 token、短数字、思维链分别为 1.000、0.30、0.000）。这是关于探针的结论，不是关于任务的。

文档自己的片段不受这个限制，因为它不是小位置组。逐 token 替换它——每个位置保持自己的旋转位置编码相位（rotary phase）——在 40 个临床计算器上于第 8 层恢复了文档效应的 0.87，对照的接收方持有一份错误的临床文档、在这些计算器上一题都做不对。由于长度匹配的接收方已经持有一份文档，这种替换满足 $h_{\text{recv}}(\text{span})+d(\text{span})=h_{\text{skill}}(\text{span})$，其中 $d(\text{span})=h_{\text{skill}}(\text{span})-h_{\text{recv}}(\text{span})$，所以它**就是**式 (1) 的内容注入，$\alpha=1$，分布在 $m$ 个位置上。剂量、拆成共享与特有两半、文档间迁移、秩截断，都可以在真实技能上于这里运行。

**哪些是新的，哪些不是。** 若干要素已经确立，我们使用而不声称：单个任务向量在功能上是秩一映射（Dong et al., 2026）；单个静态位置无法刻画思维链（Dura et al., 2026）；恢复携带信息的 token 的状态能在早中层而非晚层恢复行为（Meng et al., 2022; Geva et al., 2023）；上下文过了某个中间深度就不再重要（Pola & Balasubramanian, 2025; Sia et al., 2024）；多项选择把决策汇集到一个位置（Wiegreffe et al., 2025）。本文新的是：把这些工作混在一起的两个限制——**映射**的秩与**答案**的长度——分离开；一个能在真实文档上运行完整因果电池的通道；以及对**表示（representation）**秩的一项度量，它在同一模型家族内不随宽度缩放、在不同家族之间不同。

**贡献（Contributions）。**
1. **带匹配阴性对照的减法协议。** 在场主导几何、内容主导行为：在场成分修复救回格的 0.062——恰好等于把错误文档放进 prompt 的效果——内容成分修复 0.812（§3）。
2. **注入容量由答案长度决定**（§3.1）：一 token 答案 1.000、自由作答 0.30、思维链 0.000，只改变格式。
3. **一个能在真实文档上运行完整电池的通道**（§4）：在文档自身片段上、40 个第三方计算器上，$\alpha=1$ 时 $\rho=0.87$，对比 $\alpha=0.5$ 为 0.06、另一技能家族 0.06、打乱位置 0.08、噪声 0.10、零臂 0.00。
4. **作用需要多少方向**（§5.2、§5.3）：秩 128 时 0.77，底部 64 个方向为零；在宽度四分之一的模型上 $k^{*}=40$（对比 52 以及预注册的宽度比例预测 12），但在同宽度的第二个家族上为 64–84。
5. **片段是「不再是通道」而不是「变窄的通道」**（§5.1）：在四层（12–15）写入恢复 0.96，在二十层（16–35）写入只有 0.11，而对它的注意力在深得多的层仍然重要；这一分离在两个任务、两个家族上复现。我们也撤回一个机制：片段参与比表面上的崩塌是超大激活（Sun et al., 2024）。
6. **三个度量陷阱**（§7），以及一个恒等干预改变了 6% 思维链答案的实验仪器，我们追查到是 kernel 选择差异并修复（§2）。

## 2 实验设置（Setup）

**材料与指标。** MedCalc-Bench 题目（Khandekar et al., 2024）配 SRA-Bench 中由他人撰写的技能文档（Su et al., 2026）——55 个计算器 × 每个 20 个实例 = 1,100 题，用基准自带评分器判分，模型以思维链作答。一个合成阳性对照（虚构单位制，一页文档给出换算表）提供保证为零的地板和可生成的长度匹配对照。除非另有说明，因果实验在 Qwen3-8B（Yang et al., 2025）上进行；§5.3 增加 Qwen3-0.6B、Qwen3-1.7B、Mistral-7B-Instruct-v0.3（Jiang et al., 2023），以及第二个领域：SRA-Bench 中的 TheoremQA（747 道题、320 个技能，逐字使用基准的 prompt 和评分器）。各臂同时报告原始准确率和

$$\rho(\text{arm})=\frac{\text{acc(arm)}-\text{acc(receiver)}}{\text{acc(donor)}-\text{acc(receiver)}}\qquad(2)$$

区间按计算器做 bootstrap（有放回重抽样估计置信区间），因为同一计算器的 20 个实例共用逐字节相同的文档。

**四格（Four cells）。** 每道题按文档对它做了什么打标签：**R**（救回，rescued）、**F**（持续失败，persistent failure）、**K**（保持，kept）、**B**（破坏，broken）。**R 是唯一能证明文档在起作用的格**；所有表都按格读，§7 表明四格合并后的聚合量相对 R 可以符号相反。同样 1,100 道题上三个臂：金标 74.2%，无技能 34.5%，错误技能 31.5%。

**零臂，以及它发现的一个仪器故障。** 每次运行都带一个**零臂**：把接收方自己的片段状态写回自身，这是恒等操作，必须复现未打补丁的接收方。在本工作的大部分时间里它并不完全做到——在 Qwen3-8B 上，1,766 对观测中只有 93.9% 一致，108 个双向翻转，翻转率随模型增大（两个小模型为 0.7%）。流水线是确定性的（两台机器在全部 360 个题×臂单元上一致），所以不是运行间随机波动。原因是实现故障而非模型性质：捕获前向调用模型时没有显式 attention mask，解码前向带了 mask；对单条无填充序列，两者数学上等价，但会选用不同的注意力 kernel，两者在第 8 层相差状态幅度的 1.2%，在第 34 层相差 25%。两处都传 mask 后零臂变得严格——两次重跑 80/80。从 §4 起的所有片段通道数字，除非标注「修复前」，都来自修复后的运行；§3 的末位置与合成任务结果以及几何度量早于修复（附录 C.11）。一个行为上不是恒等的恒等干预，在单个答案 token 上看不出来，但在长生成里会变成六个百分点的地板；依赖 kernel 的数值是已知的非确定性来源（He & Thinking Machines Lab, 2025），但我们很少看到有人报告这个对照。

## 3 哪个成分在起作用，以及一个位置能携带什么

我们把式 (1) 的每个成分加回提示末位置的无文档状态，继续前向，并以直接把状态替换为 $h_{\text{skill}}$ 作为上参照。这个协议需要一个有精确零地板和匹配阴性对照的任务，因此在合成任务层上用 Qwen3-1.7B 建立（附录）；这是合成材料唯一独立承担论证的地方。**在场成分什么也没修复，但并非无作用**——单独加它把救回格带到 0.062，恰好等于把错误文档放进 prompt 的效果。**内容成分修复了大部分**，0.812，上参照为 1.000，而它曾被每一项几何度量当作小残差忽略。**并且补丁复现了文档完整的行为签名**：在四格上，整体替换给出 1.000/0.000/1.000/0.000，加 $d_i$ 给出 0.812/0.112/1.000/0.125。只会帮忙的补丁可以用笼统的「更努力一点」解释；一个同时恰好破坏文档所破坏的题的补丁，携带的是文档的决策。减去哪个对照决定了度量的是什么：相对无关文档，$d$ 修复 0.812；相对把所有数字替换掉的同一文档，0.23–0.31；相对句子打乱的同一文档，0.19–0.29——相差三到四倍，所以不指明对照的「内容成分」不是一个有定义的量。

### 3.1 一个位置能携带的是答案，不是内容

上面是多项选择的结果，那么这一个位置到底携带什么？同样的题改成自由数值作答就崩溃了：直到第 22 层所有条件都读数为零，包括整体替换；任何单位置干预的最好成绩是 0.304——而**排序**不变，内容 0.268（占 0.304 中的大部分）对在场 0.018。是格式而不是模型：同一模型同一批题在多项选择形式下，完全相同的扫描恢复 1.000。原因可以数出来：120 道题里没有一道金标答案是单 token（36 道两 token、55 道三 token、29 道四 token），而单个 prompt 位置的补丁最多只能修正第一个生成 token；多项选择把答案压缩成恰好一个 token，这正是单位置补丁搬运的单位。补丁放在最后 $k$ 个位置上证实这是容量而不是阈值：$k=1,4,16$ 分别恢复 0.286、0.286、0.554。

让答案长度成为**唯一**变化的量就能定案。同样 80 道题、同一模型、同一文档，要求逐步推理：技能价值 0.000→1.000，可恢复的效应比另两种格式都大，而单位置补丁恢复 **0.000**。三种格式下救回格分别有 44、56、80 道题，补丁分别恢复 1.000、0.304、0.000。在第三方临床技能上，同一个探针什么也读不到——替换末位置在 18 道救回题里最多修好 3 道（第 10 层），从第 14 层起只有 0–1 道；把**题目**片段（50 到 1697 个位置）移植进长度匹配的接收方，在七个层中任何一层都修不好任何一题，而零臂逐题落在接收方基线上。

## 4 真正携带作用的通道，以及在其中运行的完整电池

**接收方，以及为什么移植**就是**注入。** 供体是有文档的前向；接收方是同一个 prompt，但文档被逐 token 替换为一份固定的无关临床技能，于是每个位置保持旋转相位，接收方是一个「活的」干扰项而不是填充物。把供体状态写进这些位置因此在片段上满足 $h_{\text{recv}}+d=h_{\text{skill}}$：这就是在 $m$ 个位置上以 $\alpha=1$ 注入 $d$。下面每个臂都是对 $d(\text{span})$ 的向量运算。它不是重新运行金标 prompt：只在一层施加，片段以外的一切保持接收方的状态，它在第 8 层恢复 0.85，在第 16 层恢复 0.19（§5.1）。

**它完整地携带作用。** 图 1 把两个通道放在同一批题上并排比较。在末位置，五个臂——内容成分、在场成分、另一实例的供体、另一技能的供体、整体替换——全部落在无文档模型的 0.10 以内。在文档自己的片段上，移植把需要文档的题从 0.00 带到第 8 层的 1.00（$n=16$；40 个计算器上为 0.87，表 2）。差别不在向量，而在写到哪里。

> **图 1**（`fig-channels-medcalc.pdf`）：同一个内容向量，写在两个地方。第三方临床技能，Qwen3-8B，答案从模型自己的推理中判分。上：写进提示末位置，每个臂取第 10、14、20、30 层中最好的一层，对照无文档地板。下：在第 8 层写在文档自己的片段上，对照它自己的接收方地板。下半部分限制在「接收方（错误临床文档）从不解对」的计算器上，因为在其他计算器上模型不需要文档，一个连贯的替换就能让它退回到自己已知的东西；不限制的版本和该比较见附录。误差棒为 bootstrap 95% 区间。

**它表现得像机制，而不是扰动。** 四项对照，都在第 8 层，都在错误文档从不救回的计算器上读。**剂量**是阶跃而非斜坡：$\alpha=0.4, 0.5, 0.55$ 给出 0.06、0.00、0.06，$\alpha=0.6, 0.7, 1.0$ 给出 0.62、0.94、1.00（$n=16$，四个计算器）——整个过渡发生在剂量 0.55 到 0.7 之间。**迁移**：写在两份文档共享的前缀上，另一技能的向量给出 0.19，而同样位置上本技能自己的向量给出 0.94（$n=16$）；在 40 个计算器上是 0.06 对 0.73，无论供体是否计算同一个量，所以失败在于供体，而不在于子片段。**顺序**：同一组向量在片段自身位置间打乱，给出 0.08。**噪声**：逐位置范数匹配的高斯噪声给出 0.10，零臂 0.00（两者都在表 2 的 40 个计算器上）。

**这些数在哪个子集上读。** 在 10 个开发计算器中的 6 个上，接收方——一份错误的临床文档——已经能解对其中一些题：模型认识这个计算器，只需要被告知该跑哪一个。在那里文档不是必需的，另一技能的供体读数 $\rho=0.47$，其余计算器上为 0.19（$n=24$ 和 16），所以在混合集上读的迁移臂，会把部分**释放**报告成迁移。所有因果数字都在接收方从不解对的计算器上读——这是加在对照上的条件，从不加在供体或处理臂上。

**它在四倍数量的技能上复现。** 在 **40** 个计算器上运行、并在更大的集合内重新计算限制集，有 15 个依赖文档，剩 60 道题，每个臂都成立（表 2）。

## 5 内容在网络的哪里可读

### 5.1 充分性与必要性在深度上意见不一

「文档状态**能不能**在第 $L$ 层被交接」与「模型在第 $L$ 层**是否还在**读它们」给出不同答案，在我们运行的每个模型和任务上都是如此。

充分性，40 个计算器（限制后 $n=60$，20 个计算器）：单层的片段状态在 36 层中的第 0、4、8、12 层复现 $\rho=1.04, 0.94, 0.85, 0.77$，然后下降——第 14 层 0.28，第 15 和 16 层 0.19，第 20 层 0.15。交接在约 0.4 深度处结束。

必要性，来自累积注意力屏蔽（$n=40$）：从第 $L$ 层到末尾屏蔽所有位置对文档的注意力，对所有 $L\le 20$（$L=4$ 除外，0.33）剩下 0.08–0.15 的题答对，然后第 24 层 0.38、第 28 层 0.75、第 32 层 0.95。**在单层交接于 0.4 处失效很久之后，模型在 0.7 深度处仍在读文档。** 这一分离在我们运行的每个模型和任务上都复现（§5.3，表 3）；边界落在哪里则不复现。在 Qwen 家族内，交接在两个任务、两个宽度上都结束于同一相对深度（0.33–0.43）；Mistral-7B 交接早得多（两个任务上都是 0.19–0.22），却在 0.62–0.88 处仍在读文档；必要性边界随任务移动（Qwen3-8B 上 TheoremQA 为 0.56，MedCalc 为 0.78）。

**不是一层太少，而是通道关闭了。** 在**每一层**同时写入片段恢复 0.950（修复前），这让「一层不够」成为自然的解读。这是错的。只在一个窗口内的每层写入、其余层不写，20 个计算器上（$n=48$）：第 8–11 层 $\rho=1.00$，12–15 层 0.96，14–19 层（跨越边界）0.38，16–35 层 **0.11**——与单独在第 16 层写入相同，零臂恰好为 0.00。**四层就够，只要是第 12 到 15 层；二十层毫无价值，只要从第 16 层开始。** 在 TheoremQA 上同样的窗口给出 0.90、0.73、0.45 和 0.21，最后一个等于单独第 16 层。过了交接点，这些位置不再是进入计算的路径——不是窄路，是没有路。

**片段并没有变成摘要；说它变成摘要的那个度量是伪影。** 片段内容矩阵的去中心化参与比在第 12 层为 64、第 16 层为 17，好像文档恰好在交接失效处被压缩了。它是单层的阶跃，在 Qwen3-0.6B 和 Qwen3-1.7B 中不存在，而且它就是超大激活（Sun et al., 2024; Shi et al., 2026）：在第 16 层，40 份文档中有 34 份各有一个 token 获得了片段中位范数 99 到 180 倍的状态，落在同样两个隐藏维度上。去掉四百个位置中最「响」的四个，参与比恢复到 66，这样度量时从第 0 层到第 28 层是平的（附录表 prdiag）。交接失效时表示并没有丢失维数，我们不知道它丢失了什么。任何不排除超大激活的残差流谱统计量（Fernando & Guitchounts, 2026; Sarkar & Deka, 2026）都会在超大激活出现的那一层报告「崩塌」，就像异常维度（rogue dimensions）对相似度度量的影响一样（Timkey & van Schijndel, 2021; Kovaleva et al., 2021）；我们建议在任何谱统计量旁边报告逐位置范数比（这里中位数从 1.6 变成 150）。

### 5.2 作用需要多少方向：我们截断秩

到目前为止的每项度量说的都是作用**在哪里**。这一项说的是它**有多大**，用的是任务向量文献中唯一可比较的单位：模型用到被注入对象的多少个方向。设 $d\in\mathbb{R}^{m\times D}$，$\bar d$ 为其在位置上的均值，

$$d^{(k)}=\bar d+\sum_{i=1}^{k}\sigma_i u_i v_i^\top,\qquad d-\bar d=\sum_i\sigma_i u_i v_i^\top\qquad(3)$$

保留均值、只截断变化部分，所以 $k$ 可与去中心化参与比相比较。注意保留均值意味着什么：每个截断臂本身已经包含**「这份文档的一个向量写在它片段的每一个位置上」**，这是任务向量在这里能采取的最宽松形式。底部 64 对照的方向几乎不携带能量，实际上就是只有这个均值。

一个方向不够，十六个也不够（图 2）。在第 8 层、40 个计算器上（$n=60$），$k=4, 16, 32$ 时恢复 0.13、0.06、0.13，然后 $k=64$ 时 0.54、$k=128$ 时 0.77，不截断为 0.87；曲线在 $k=16$ 以上区间的一半在 $k^{*}=52$ [43, 72] 处恢复，为宽度的 1.3%。10 计算器的开发曲线（修复前）补充了 $k=1,2,8$（0.11、0.06、0.11），给出 $k^{*}=45$。改为保留**底部** $k$ 个方向——同样的秩，被丢弃的那一半谱——$k=16$ 时 0.06，$k=64$ 时 0.00：起作用的是谱的顶部，不是方向的个数。在更深处重复——第 12 层，以及文档放在问题之后时的第 16 层——两个拐点都在 64 和 128 之间，并不更低（修复前，$n=16$ 和 28；附录）。

> **图 2**（`fig-rank-medcalc.pdf`）：在注入前把内容矩阵截断到秩 $k$，40 个计算器，修复后，每个模型都在自己的交接点之前注入。Qwen3-0.6B 的宽度是 Qwen3-8B 的四分之一，其拐点并不更低（$k^{*}=40$ 对 52；按宽度比例的解释会把它放在虚线处）。Mistral-7B 与 Qwen3-8B 同宽，却需要更多（$k^{*}=84$）。虚线对照保留**底部** $k$ 个方向——同样的秩、被丢弃的一半谱。$\rho$ 按 prompt 中的文档归一；不截断的移植分别为 0.87、0.89、0.92。区间按计算器 bootstrap。

## 6 内容成分属于什么

四项性质，每项都是同一电池里的一个臂，都在限制集上读；附录给出数字和对照。它**不是一个共同的「有文档在场」位移**——对所有技能平均 $d$ 并写入这个平均值，恢复 $\rho=0.11$（文档放在后面时 0.06；修复前），而它占每个向量能量的 54–60%。它**不是幅度**——逐位置缩放到接收方自己的范数不改变任何东西（1.06 对 1.06；修复前）。它是**技能，而不是技能加任务**：文档在问题之前时，因果掩码使片段状态在同一技能的 20 个实例间完全相同（等长 prompt 逐比特相同，否则余弦 ≥ 0.997），所以向量不可能包含任务信息，因为它看不到任务；把文档放在问题**之后**（这时它能看到任务），在第 8 层另一实例的向量恢复得和本实例一样多（0.96 对 1.00，$n=28$），实例特有的残差只恢复 0.04。这只在第 8 层成立：在第 16 层，另一实例的向量恢复 0.48，本实例为 0.85，而残差单独仍然只有 0.04，所以到那时片段已经吸收了问题中某些东西，而这些东西两部分单独都不携带。它**集中在公式里**。解码 token 的切分给出四段：一段文字描述、公式、工具签名、一道例题。在 40 个计算器上一次只写一段（$n=60$），分别恢复 0.12、**0.56**、0.12、0.12：三段各自都在对照地板上，而公式单独只达到整份文档 0.87 的三分之二，所以其余部分只在组合中起作用。把文档移到问题后面，交接在第 16 层仍然开着（10 个计算器上 0.85；文档在前时 40 个计算器上 0.19），所以交接深度不是网络的固定性质。

## 7 这种度量会误导的三种方式

我们有三项度量在正确之前是错的（附录）。**聚合对数概率把对照排在最前面**：对所有题平均，在最后一层，金标答案的对数概率让一个不含内容的均值向量比模型读文档时实际构建的状态**高** 3.75 nats，而准确率是 0.256 对 0.436——一个被拉平的分布永远不会给出 −19 nats，也永远到不了 argmax；在第 21 层，文档不起作用的格贡献了差距的 133%。**多项选择制造地板**：把所有数字替换掉的文档在多项选择里保留近四分之三的效应，在自由作答里一点不剩，因为这种格式把检索算作成功（Balepur et al., 2024）。**错误文档对照不等于无文档对照**：槽位里任何一份文档都会把救回题从地板上抬起来（无文档 0.025，无关文档 0.150–0.250），所以「有」对「无」同时度量了在场和内容——这就是为什么这里每个臂都对照一个持有文档的接收方来度量。

## 8 相关工作（Related work）

**一个向量能携带什么。** 上下文可压缩为激活空间中一个方向，这在上下文示例上（Hendel et al., 2023; Todd et al., 2024）以及权重空间的微调上（Ilharco et al., 2023）已经确立。对这一做法已知有两个限制，而且它们不是同一个限制。Dong et al.（2026）证明一个注入的任务向量在功能上是秩一映射，这**解释**了我们发现的「整个题集共享的一个向量在 39 行查表上恢复 0.062」。本文关心的限制在映射的另一侧：本题自己的 $d_i$ **尽管**面对同样的高秩映射，仍通过同一个单位置恢复 0.812，因为答案是一个 token；而在临床技能上什么也恢复不了，因为答案有几百个 token。秩约束一个向量能表达哪些映射；长度约束任何小位置组能携带多少决策，与映射无关（Dura et al., 2026 断言了后者；§3.1 度量了它）。单向量压缩最强的正面结果 Ardoin et al.（2026）在两方面都与此一致：它成功的每个任务都是短答案，其最优配置在**早**层注入。连同 Wiegreffe et al.（2025）把答案**符号**的选择定位到一个中间层，三者都说明单个向量是模型已有行为之间的**选择器**。训练过的压缩器确实能把长上下文压进少数位置（Mu et al., 2023; Ge et al., 2024），在**每个**位置都加一个方向能引导长生成（Panickssery et al., 2024; Liu et al., 2024; Stolfo et al., 2025）；我们的限制针对的是未经训练、写在一个位置上的补丁；而该位置**编码**了即将生成的回答的性质（Dong et al., 2025）是解码层面的结果，不是搬运层面的。Mehrafarin et al.（2026）展示了答案位置确实持有什么——从模型**自己已完成的**思维链中打补丁到一个晚位置，在 GSM8K 上恢复 ≥99%，而我们的供体取自任何推理之前，什么也恢复不了——Da Silva et al.（2025）则从另一个方向报告了同一通道的失败。

**有四样东西都被称为「秩」；以及激活修补。** Dong et al.（2026）约束的是**任务映射**的秩；Sarkar & Deka（2026）约束的是**雅可比矩阵**的秩，报告它是层内禀的、不随模型大小变化；Fernando & Guitchounts（2026）约束的是**复合算子**的秩，发现 65 倍的崩塌。我们度量的是一个**表示**的秩，$d\in\mathbb{R}^{m\times d}$，而且是四者中唯一截断被注入对象本身并读出行为的。对描述性的度量（包括我们自己的）有一条告诫：Sun et al.（2024）记录了在固定维度、少数位置上比中位数大三个数量级的激活，出现在单一层（Shi et al., 2026），所以过了那一层的残差流谱统计量其实是关于它们的统计量（§5.1）。方法上我们遵循 Zhang & Nanda（2024）和 Heimersheim & Nanda（2024）；Pola & Balasubramanian（2025）和 Sia et al.（2024）发现过了某层上下文就不再重要，这是我们屏蔽结果的反方向版本，也是 Wang et al.（2023）「浅层读、深层提取」信息流所预言的；Li et al.（2025）、Abdelsalam et al.（2026）和 van Dort & Heuss（2026）定位了可迁移的任务信号，但没有分离在场与内容。另一条平行路线用权重而非激活替代文档（Charakorn et al., 2026; Caccia et al., 2025）。

## 9 局限（Limitations）

**范围。** 电池在 $n=40$ 上开发，并在 40 个计算器、第二个领域和两个额外模型上重跑；结论是经受住这些检验的那些。通道、深度扫描和秩截断有三个模型、两个任务；屏蔽有两个模型；文档顺序比较和文档内定位只有一个模型、一个任务；宽度论证依赖同一家族内四倍的宽度差，$k^{*}$ 依赖一个限制了 Mistral-7B 拐点的网格。另外两个 SRA-Bench 领域标出了方法失效的地方：LogicBench 的答案多为二值（$n=57$），半剂量恢复 0.44、另一技能 0.38，而移植为 0.75，并且没有悬崖——扰动会偶然翻转一个二选一答案——CHAMP 只剩 20 道救回题。ToolQA 和 BigCodeBench 需要工具调用或沙箱执行，被排除。早于仪器修复的结果——合成任务层、末位置扫描、10 计算器秩曲线及其更深层的重复——在附录中标注。

**因果结论针对哪些题。** 救回格，且在其中只针对接收方从不解对的组（§4）：40 个计算器中的 15 个、60 道题。两个条件都加在对照上。

**秩和窗口结果不能确立什么。** 我们不声称深层缺的是秩，而且截断补丁可能打开未打补丁模型并不使用的通路（Makelov et al., 2024）。在第 16–35 层写入片段什么也恢复不了，这也与「后期读取依赖早期形成的绑定」相容（Feng & Steinhardt, 2024）；我们没有把两者分开。两个阴性结果：末位置没有任何表示量能区分技能救回的题和没救回的题；片段通道没有可用的对数概率读数（强制 `ANSWER:` 提示会完全消除行为效应，却留下 +0.60 nat 的差），所以这里的一切都基于准确率。

## 10 结论（Conclusion）

技能文档的作用并不由模型作答位置上的一个向量携带。那个位置持有模型的**决策**，而占据几百个 token 的决策装不进一个状态——这就是为什么写在那里的每个臂（包括整体替换）都落在无文档基线上，也是为什么一旦把答案变短作用就重新出现。作用由文档自己的 token 携带，在那里同样的减法表现得像一个机制：$\alpha=1$ 时完整，在剂量 0.55 到 0.7 之间开启，与写入的范数无关，打乱片段位置即被破坏，来自另一技能的供体则没有作用；在两个任务领域和两个模型家族上都如此；并且需要被注入对象的五十到八十个方向——这个数在家族内不随宽度缩放，但在家族之间不同。实际意义是一个适用范围条件：在提示末位置做激活修补，度量的是模型已经决定了什么，而在短答案基准上，这与度量文档提供了什么无法区分。

## A 对照文档的完整说明（Control documents in full）

$d$ 由它所减去的那份文档定义，所以「内容」就是把技能与该对照区分开的那部分东西。我们默认的对照只固定长度。另外两个更紧的对照由技能文档本身生成，固定得更多：**shuffled（打乱）**保留每个词、每个数字，只破坏行的顺序；**corrupted（破坏）**保留措辞、流程、表格布局和单位顺序，但替换**每一个换算因子**。三者都用同样的名字和标题注入，prompt 从不透露是哪一个。

**在第三方技能上的同一对照。** 我们在临床计算器上重复了破坏对照，发布的实验框架里本就有这个臂（正文中的数值常数被扰动，措辞、结构和可执行工具不变）。这份材料是自由作答、以思维链回答的，在那里被破坏的技能**毫无价值**：在 20 道救回题上得 0.050，与完全没有技能相同，而金标技能为 0.950。所以合成材料与真实材料一致，而且在关键问题上一致——破坏文档是否有代价，是答案格式的性质，而不是文档的性质。

把它当作归因而不是三个互相竞争的估计来读，它对任务的多项选择形式说出了一些令人不安的事。在全部 200 道题上，金标文档价值 0.180→0.300；打乱版本价值 0.180→0.270；每个因子都错的版本价值 0.180→0.260。度量到的技能效应中四分之三在「破坏文档顺序」或「破坏其中每个数字的正确性」后仍然存在。在这种格式下模型需要的，主要是一份包含正确词汇和正确种类数字的文档——而不是一张正确的表。正确的表只值剩下的 0.03–0.04 绝对准确率，或救回格的 0.19–0.31。

这既是关于模型的陈述，也是关于答案格式的陈述。我们在运行前登记了检验：在自由作答格式下必须把数字算出来，所以被破坏的表应当毫无价值。确实如此（表 C8）。破坏每个因子在全题集上保留多项选择效应的 0.67，而自由作答效应 0.467 **一点不剩**。打乱行顺序在两种格式下代价都很小，这也符合预期：我们的打乱是按行置换，而换算表每行就是一行，所以每个因子仍然在那里可供检索——只是不在可读的顺序里。

### C.1 秩截断与模型阶梯的详细说明

到目前为止的每项度量说的都是文档作用**在哪里**。这一项说的是它**有多大**，用的是任务向量文献中唯一可比较的单位：模型实际用到的被注入对象的方向数。

我们在写入前把片段各位置上的内容矩阵截断到秩 $k$。设 $d\in\mathbb{R}^{m\times D}$，$\bar d$ 为其在位置上的均值，$d^{(k)}=\bar d+\sum_{i=1}^{k}\sigma_i u_i v_i^\top$，$d-\bar d=\sum_i\sigma_i u_i v_i^\top$；保留均值、只截断变化部分，使 $k$ 可与去中心化参与比比较。$k=1$ 是本设定中最接近任务向量的东西：一个方向，施加在片段的每个位置上。

一个方向不够，十六个也不够（图 2）。在 40 个计算器上、修复后（$n=60$），第 8 层 $k=4, 16, 32, 64, 128$ 时恢复 0.13、0.06、0.13、0.54、0.77，不截断为 0.87；曲线 $k=16$ 以上区间的一半在 $k^{*}=52$ 处恢复（按计算器 bootstrap 的 95% 区间 [43, 72]；在 $\log_2 k$ 上插值，这是模型阶梯运行之前就固定的定义）。10 计算器的开发曲线（修复前）在 $k=1,2,4,8,16,32,64,128$ 上为 0.11、0.06、0.06、0.11、0.11、0.33、0.72、0.94，给出 $k^{*}=45$。

$k^{*}$ 以网格 $k\le 128$ 上的最大值为锚点，而不是以不截断移植为锚点。当 $k=128$ 接近不截断时（Qwen3-8B，0.77 对 0.87）这影响不大；当它不接近时（Mistral-7B，0.71 对 0.92），拐点受网格限制，更细或更长的网格可能把它往上移。

**起作用的是谱的顶部，而不是方向个数。** 改为保留奇异值最**小**的 $k$ 个方向——同样的秩、被丢弃的那一半谱——在 40 个计算器上 $k=16$ 时 $\rho=0.06$、$k=64$ 时 0.00（开发集上为 0.00 和 0.06），都在接收方水平。没有这个对照，「六十四个方向就够」无法与「任意六十四个方向都行」区分。

**需要的方向数不随深度下降（修复前，样本小）。** 如果交接在第 15 层失效是因为对象缩小了，那需要的方向数也会随之缩小。在移植仍然有效的地方、在接收方从不解对的计算器上重复截断：第 12 层（$n=16$）$k=16$ 时准确率 0.00、$k=128$ 时 0.62，不截断为 1.00；文档放在问题之后时第 16 层（$n=28$）$k=16$ 时 0.25、$k=128$ 时 0.71，不截断为 0.79——两者拐点都在 64 和 128 之间。这些运行早于修复且样本小；我们把它们读作「不更低」，而不是读作测得的拐点。文档在问题**之前**时第 16 层移植已经在地板上（$\rho=0.06$），根本没有曲线：每个截断都读数 0.00–0.06，因为已经没有作用可供截断去除。我们完全不读第 16 层文档在前对象的秩，因为那正是 §5.1 的超大激活接管其谱的层。

**显而易见的反向操作行不通，我们如实报告。** 如果深层交接失败是因为缺方向，那么给它一个秩更高的消息应当能恢复。我们试了最直接的版本——把第 8 层的供体写进第 16 层——在 10 个计算器上（限制为错误文档和无文档 prompt 都解不对的题后 $n=30$）。它没有恢复；读数 $\rho=0.00$，而同层供体为 0.06；把范数匹配到第 16 层的尺度也只恢复一部分差距（0.13）。第 8 层状态不是第 16 层状态的高秩版本，而是另一种编码，而且迁移是有方向的：Ardoin et al.（2026）发现中层到早层注入最优，而我们发现早层到中层注入有害。

### C.6 一个位置能携带的是答案，不是内容

单位置修补是这类文献的标准做法，而表 C12 是多项选择结果，所以值得问那一个位置到底携带什么。同样的题有自由数值形式，答案是模型必须算出来的数字而不是要选的选项；在那里技能价值 0→0.467，救回格有 56 道题。

两件事变了，一件没变。天花板崩塌了：直到第 22 层所有条件读数为零，包括直接把该位置替换成真实的技能状态，任何单位置干预的最好成绩是 0.304，在第 32 层。没变的是排序——内容成分恢复 0.304 中的 0.268，在场成分 0.018——所以 §3 的结论经受住了格式变化，而幅度没有（完整扫描见附录 D）。

**是格式，不是模型。** 同一模型、同一批题的多项选择形式（Qwen3-8B，$n=120$，$n_R=44$）上，完全相同的扫描在第 26 层恢复 0.977，在第 30 和 35 层恢复 1.000。同一模型、同一批题、同一干预、同样的层：答案是一个选项字母时 1.000，答案是模型要生成的数字时 0.304。

原因是机械的，而且可以数出来。120 道题中**没有一道**的金标答案在该分词器下是单个 token：36 道两 token，55 道三 token，29 道四 token。单个 prompt 位置上的补丁最多只能修正第一个生成 token；其余一到三个 token 是在仍然不含换算表的上下文中生成的。多项选择把答案压缩到恰好一个 token——这正是单位置补丁搬运的单位。改为修补最后 $k$ 个位置证实这是容量而非阈值：第 30 层 $k=1, 4, 16$ 分别恢复 0.286、0.286、0.554，所以十六个位置携带了文档所携带的约一半，而四个位置——对话模板后缀——没有多携带任何东西。

**在第三方技能上，同一个探针什么也读不到。** 在那里，把提示末位置替换成有技能状态，在 18 道救回题中最多修好 3 道（第 10 层），从第 14 层起只有 0–1 道；把问题片段——50 到 1697 个位置——移植进长度匹配的接收方，在七个层中任何一层都修不好超出接收方自身基线的题（表 C10），而自移植臂逐题落在该基线上，所以仪器是活的，零结果是真的。§4 展示了同一材料上什么是有效的。

**答案长度是原因，而且这是受控比较。** 从合成层到临床层的一步同时改变了技能、任务、prompt 长度以及补丁覆盖的比例，所以它本身无法确定是什么让注入失败。于是我们让答案长度成为唯一变化的量：**同样的** 80 道合成题、同一模型、同一文档，要求逐步推理并在最后一行 `ANSWER:` 给出答案。在这种格式下技能价值 0.000→1.000——每道题都被救回，F=K=B=0——所以可恢复的作用比另两种格式都多，救回格就是整个题集。

单位置补丁恢复其中的 **0.000**（§3.1），$d$ 和 $g$ 也一样。同一次运行中最后一层的仪器检查在 10 道题中 10 道通过。

**「技能作用由一个向量携带」成立的范围，就是答案短的范围**——于是临床结果不是那份材料的性质，而是这一规律的一个实例。

**这是容量限制，而且可以度量。** 修补一个位置是一种选择而不是一种度量，所以我们重复扫描，修补最后 $k$ 个 prompt 位置，$k\in\{1,4,16\}$。把它们替换为技能状态，在第 30 层分别恢复救回格的 0.286、0.286 和 **0.554**。四个位置什么也买不到——最后四个 token 是对话模板后缀——十六个位置（伸回到问题里）大约让恢复翻倍。相对于文档本身的 1.000，即使十六个位置也只携带约一半。内容并没有压缩进一小组位置；补丁能搬运多少，是它被给定多少位置的函数。

因此我们把低天花板读作单位置修补的适用范围条件，而不是关于 $d$ 的阴性结果。在多项选择题里答案**就是**一个位置上的一个 token，所以搬运模型决策的补丁就搬运了整个任务，看起来像是搬运了文档。提示末位置到第 21 层持有的是模型的**答案**，不是文档的内容——与「文档读取到那一层已经结束」的屏蔽结果一致（§5）。

### C.7 实验设置（完整）

**两个任务家族。** **真实技能，主要材料**：MedCalc-Bench 实例配 SRA-Bench 发布的 55 个金标计算器技能——55 个计算器 × 20 个实例 = 1,100 道题，按数值容差确定性判分，判分回路中没有模型。技能和任务都是别人的，这让效应量可信。Qwen3-8B，单轮，无工具，贪心解码；区间按**计算器**做 bootstrap，因为共享同一计算器的 20 道题不独立。**合成阳性对照**：虚构单位制，一页文档给出换算表，所以无文档地板有保证、不可能被污染，并且我们确切知道「内容」是什么。题目由换算表生成（$n=358$），答案出现在例题中的题一律删除。

**两个因变量。** 准确率（贪心解码的自由作答，用任务自带评分器判分），以及金标答案的 teacher-forcing 对数概率。两者失败方式不同、分歧足够频繁，只报告其中一个是不安全的（§7）；全文优先读准确率。我们没有为了得到准确率通道而把任何题改写成多项选择——附录 C.14 说明这种改写并非无害。

**如何读一个臂的数字。** 干预同时报告为原始准确率，以及它可能恢复的范围中的比例 $\rho$（式 2），其中接收方是被写入的、未打补丁的 prompt，供体是实际放入文档的 prompt。$\rho$ 能跨设定比较而原始准确率不能：图 C5 的四种配置中供体为 0.550、0.467、1.000 和 0.950，接收方从 0.000 到 0.350；本文早期草稿曾比较 0.408 与 1.000，报告某通道在更长答案下**更强**，而按比例它们是 0.87 和 1.00。每个标为「fraction」的图轴都是式 (2)。

**仪器自身的噪声地板，实测。** 每次解码运行都带一个**零臂**：捕获接收方自己的片段状态并写回自身。在长度匹配的接收方上这是逐比特恒等，所以零臂必须在每一层都等于未打补丁的接收方。在附录 E 的修复之前它并不完全如此。在 Qwen3-8B 上，所有同时带这两个臂的修复前运行共 1,766 对观测中，零臂与接收方在 93.9% 的题上一致：108 道翻转，46 道由错变对、62 道由对变错，符号检验下对称（$p=0.15$）。流水线本身是确定性的——同一配置在两台不同机器上在全部 360 个题×臂单元上一致——所以这不是运行间波动，而是仪器可复现的性质：捕获和解码两次前向用了不同的注意力 kernel，使写回的状态在第 8 层偏离 1.2%，而因变量是几百 token 长的思维链的结尾，长到足以在某处改变一次 argmax 并传播下去。它随模型变大：同一臂在 Qwen3-0.6B 上翻转 0.6%（1,696 对），在 Qwen3-1.7B 上 0.8%（1,338 对），在 8B 上 6.1%。修复后严格为恒等（80/80）。

全文用到三个推论。第一，**在修复前运行中，8B 上小于约六个百分点的效应无法分辨**，无论二项区间怎么说。第二，地板不均匀：在持续失败格上是 16%，是平均的两到三倍，这正是位于决策边界上的题应有的表现，所以在该格上读的数字对应更粗的刻度。第三，在限制集上修复前的零臂读数是 0.034 而非零——限制集以接收方失败为条件，所以翻转只能向上——因此修复前的片段数字对照的地板是 0.034；修复后它恰好为 0.000，这就是表 2 中 0.750 所对照的地板。我们很少在修补文献中看到有人报告这个对照；在单个答案 token 上它小到看不见，只有当因变量是长生成时才变大。

**四格。** 每道题按文档对它做了什么打标签：**R**（救回：无文档错、有文档对）、**F**（持续：两种都错）、**K**（保持：两种都对）、**B**（破坏：无文档对、有文档错）。**R 是唯一能证明文档起作用的格**，这里每张表都按格读，§7 表明四格合并的聚合量相对 R 可以符号相反。

### C.8 三个度量陷阱（完整）

#### C.8.1 聚合的金标答案对数概率把对照排在第一

对所有题平均，在第 27 层（最后一层），各补丁条件下金标答案的对数概率排序为

> 均值向量 −2.85 ＞ 填充状态 −5.20 ＞ **真实技能状态** −6.60 ＞ 无文档 −7.30 ＞ 错误技能 −10.29，

即一个不含内容的平均向量比模型读文档时实际构建的状态**好** 3.75 nats，而准确率是 0.256 对该状态的 0.436。

§2 的四格从算术上解释了这一差距（表 D1）：在第 21 层（差距 2.75 nats），F 和 B——文档不起作用的格——贡献了其中的 133%，而在 R 上真实状态赢 2.5 nats、准确率高 0.69。机制在选项分布上可见：均值向量把四个答案 token 上的熵从 0.187 提高到 0.972 nats（最大值 $\ln 4=1.386$）。一个被拉平的分布不可能给任何 token −19 nats，所以恰恰在真实状态自信地答错的地方它看起来极好；而拉平永远不会把一个 token 推上 argmax，所以准确率不动。两个通道唯一一致的一点是**错误技能**在两者上都最差——这是内容特异性的正面证据，因为注入错误内容会主动误导。

实用规则是：在混合题集上的聚合对数概率，度量置信度校准的程度不亚于度量内容；按结果格分解是分辨两者最便宜的方法。

#### C.8.2 前向传播受损的一段层

第 17 到 20 层之间所有补丁条件一起改善，条件之间变得无法区分。按格读能分离出原因：在 K 格上——模型本来就答对的题——真实状态补丁把金标对数概率从第 16 层的 −1.6 降到第 18 层的 −7.1，而在同样长的 prompt 上构建的填充状态补丁保持在 −1.5。凡是落在 17–20 层的迁移或恢复数字，报告时都标出这一段。

#### C.8.3 错误文档对照到底值多少

固定 prompt 的长度、结构和文档槽位置，只改变槽里放什么，能得到一个通常的二元比较（有文档/无文档）做不到的有序比较。在救回题上、其他一切相同（$n=40$，括号内为区间）：完全无文档 0.025 [0.000, 0.073]；槽里放非临床散文 0.250 [0.116, 0.384]；本技能自己的配对中性文档 0.175 [0.057, 0.293]；一份固定的错误临床技能 0.150 [0.039, 0.261]；金标文档 0.950 [0.882, 1.000]。

由此得出两点，一点可靠一点不可靠。可靠的一点是：错误文档对照与无文档对照不是同一个对象：槽里任何文档都会把这些题从地板上抬起，所以报告「有文档」对「无文档」的论文度量的是在场加内容，而在一个按「无文档时失败」挑出来的格上，在场部分不可忽略。这就是为什么 §4 的每个臂都对照一个持有文档的接收方，而不是空槽。

不可靠的是排序。临床干扰项比无关散文代价更大（0.150 对 0.250）是我们预期的方向——近似的错误应比明显的错误更糟，三个条件也按这个顺序排列——但在 $n=40$ 下每一对区间都重叠，所以我们报告一个方向而不是一个结果。我们标出它，是因为能定案的设计很便宜，而这份材料也支持：这 55 个技能天然包含分级的近似错误（校正 QT 间期有四个不同公式，delta gap 有两个），所以「错误文档要多相似才会有害」可以在有序尺度上而不是二元尺度上度量。我们没有运行这个实验。

**片段的表示**并没有**变成摘要，说它变成摘要的度量是伪影。** 悬崖最显然的解释是片段到那时已被压缩，而最显然的度量也同意：片段状态的去中心化参与比（数片段各位置在多少个方向上不同）在第 12 层为 64、第 16 层为 17——同一区间。我们在这里报告它，是因为我们曾相信它、在它上面建了一个机制，而它是错的。

三件事暴露了它。它是阶跃而不是斜坡：片段状态的参与比在第 14 层每道题都在 47 到 75 之间，在第 16 层 40 道中 34 道低于 5（表 C2），而内容矩阵在第 16 层的均值 17 不描述任何一道题——40 道中 32 道低于 5，其余 8 道为 81。四百个位置上参与比为 1.0，意味着去中心化后的片段是秩一的，而这不是能对模型仍要继续处理的四百个 token 文本说出的话。并且在 Qwen3-0.6B 和 Qwen3-1.7B 上的任何深度都没有这种崩塌（45–99，没有低于 5 的题），尽管它们的移植悬崖在相对深度上位于同一处（§5.3）。

原因可以度量，而且是已知的。在第 16 层——而不是更早的任何一层——40 份文档中 34 份各有一个 token 获得范数为片段中位数 99 到 180 倍的状态，落在隐藏维度 2276 和 676 上，34 份中完全是同样两个维度。这就是 Sun et al.（2024）的超大激活现象，它在每个模型家族出现于单一层（Shi et al., 2026）；在这个模型里「响」的 token 是文档内部靠后的一个分隔符，而不是序列开头。去中心化的谱于是被那一个位置占据：前 8 个维度在第 16 层占方差的 97.7%，而第 14 层为 5.4%。去掉四百个位置中最响的四个，参与比恢复到 66；把每个位置单位归一化，恢复到 68；去掉前 8 个维度，得到 27。按这三种方式中任何一种度量，片段维数从第 0 层到第 28 层都是**平的**，只在最后几层下降（表 C2）。

所以诚实的陈述是较窄的那个。单层交接在第 14 到 16 层之间失效；文档的表示在那里并没有丢失维数；我们不知道它丢失了什么。§5.2 确立的是另一个仍然是因果的事实——被注入对象需要多少方向——而在修复前第 12 和第 16 层的小样本重复中，这个数也并不更低（附录 C.1）。

**关于残差流参与比的警告。** 有效秩、参与比和内在维数常被计算在残差流激活上，包括报告随深度崩塌的工作（Fernando & Guitchounts, 2026; Sarkar & Deka, 2026）。超大激活从固定层开始，由少数维度在少数位置上携带，大到自己就能占据一个谱。任何不排除它们的此类度量，都会恰好在出现层报告崩塌，无论表示是否改变。我们自己的草稿就这样做过。我们建议在任何谱统计量旁边报告逐位置范数比；这里它的中位数在该层前后从 1.6 变为 150。

### C.10 内容成分属于什么（完整）

如果 $d$ 是一个「技能向量」，它应当可复用：从一个任务提取，在另一个任务上起作用。它的**方向**可以复用。它的**作用**不能，而两者之间的差距正是发现。

**起作用的那个向量不含任务信息，我们检验而不是论证这一点。** 本节到此为止讲的都是末位置那个不起作用的向量。起作用的那个——文档自身片段上的内容成分——有一个让问题变得尖锐的性质。在行为运行使用的 prompt 格式中，文档在问题之前，所以因果掩码使文档的隐藏状态只是系统文本和文档的函数。同一技能内文档在各实例间逐字节相同，所以 $d(\text{span})$ 对该技能的每个实例都应当是**同一个张量**。

确实如此。在因果集的 10 个计算器上，文档片段在每个 prompt 中都占据 token 位置 43 到 $43+m$，那里的 token id 在实例间两两相同（40 份病历中零个不同位置），把两个 prompt 截断到片段末尾再前向，相对差为 0.0。在完整 prompt 中，状态在第 0 层相对差 $3.5\times10^{-3}$、第 8 层 $8.6\times10^{-3}$，没有任何位置余弦低于 0.999——这是不同序列长度下累积的 bf16 舍入，不是内容。解码臂在行为上显示同样的事：其他实例向量的均值与本实例向量在每个运行均值上一致到三位小数，$d_i$ 与该均值正交的分量正好落在接收方基线上。

所以复现文档全部作用的那个向量只是文档的函数，与其他任何东西无关。无论「技能向量」应当是什么，这一个不是技能与任务的联合编码；它就是技能，而且是充分的。补充实验——把文档移到问题之后，使其状态**能**看到任务——见附录 C.12 最后一段。

**方向随技能而异；作用不迁移。** 在临床材料上每个技能有 20 个实例，所以「同一技能、不同任务」可以直接度量。同一计算器下不同病历的内容向量在第 20 层余弦 0.789、第 30 层 0.876；不同计算器之间为 0.320 和 0.653（$n=40$，Qwen3-8B）。在合成层上类似的切分是按换算家族，最后一层家族内 0.859、跨家族 0.699。$d$ 的方向携带文档的身份，随深度越来越明显。它在末位置的作用却不：注入均值方向 $\bar d$ 或另一道题的 $d_j$，在自由作答格式下 16 个层中每一层都修复 0.000，而本题自己的为 0.268；在多项选择中均值、同家族供体、不同家族供体分别达到 0.062、0.292 和 0.167，而 $d_i$ 为 0.792（表 D10）。唯一看起来供体可迁移的层段，正是 §7 独立识别出的前向受损、所有条件一起上升的那一段。

**它没有任何特征能区分救回题与持续失败题。** $d$ 和 $g$ 的范数与夹角在两格间一致到三位数字（第 30 层，8B，真实技能：$\|d\|$ 189.4 对 185.4，$\cos(d,g)$ −0.469 对 −0.468）。问题片段上的一个表示相似度度量在金标技能下于第 10–16 层确实能区分它们（−0.0037 到 −0.0070，区间不重叠，$n=150+150$）——而在长度匹配的**错误**技能下区分得同样好（−0.0035 到 −0.0056）。零个层通过设计中预先要求的对照，所以看起来像「技能在这里起作用了」的签名，其实是「有一份文档在场」的签名：附录 B 的陷阱低一层的版本，也是我们报告因果通道而不是相似度分数的原因。

**内容成分的大小取决于写在哪里。** 在末位置，内容成分在第 6 层是它所替换状态的 6% 扰动（$\|d\|=2.3$，$\|h_{\text{no}}\|=37.3$），到第 35 层升到 51%——而在每一层它都没有因果作用。在文档自己的片段上，同样两个条件之差在每个深度都是状态的 95% 到 115%（表 C7）——是替换而不是轻推——并且因果上完整（§4）。区分两个地方的不是文档写进去多少，而是写进去的东西是否就是下游计算读取的全部。

**共享部分携带范数，不携带作用。** 每道题的 $d_i$ 有 73% 到 99.7% 落在共享均值方向上，取决于层（表 D9）；其余部分占据 2048–4096 维中有效的 3–18 维。可复用部分几乎是全部范数，在自由作答中是零作用；在多项选择中它值本题自己向量所达到的 0.79 中的 0.06。因此「每个技能一个向量」对注入**看起来**是什么是公平的描述，对它**做了**什么是错误的描述，这与附录 B 中低一层的颠倒是同一回事。

### C.11 片段电池（完整）

§3.1 是关于探针的阴性结果，不是关于模型的。探针失败，是因为一个位置装不下占据几百个 token 的决策。显然的修复是不再只用一个位置，而最自然的替代，是唯一一组大小随文档增长的位置：文档自己的 token。

**接收方。** 供体是有文档的前向；接收方是**同一个 prompt**，文档 token 被一一覆盖为**一份固定临床技能文档**的 token——对每个实例和每个技能都是同一份，并且它不是其中任何一个的金标文档。

这一选择的两半都是被度量逼出来的。它必须固定，因为用每个技能自己配对对照构造的接收方会让接收方状态依赖于实例，于是每个形如 $h_{\text{recv}}+(\cdot)$ 的臂都会继承一个依赖实例的地板；实测有文档状态在同一技能的实例间相对变化 $3.5\times10^{-3}$，而这种接收方变化 0.36。我们用**临床**文档而不是中性散文，因为这正是行为运行中称为「错误技能」的条件，使接收方基线的含义与本文在场效应的含义一致；附录 C.8.3 把两者并排度量，发现相近（0.150 对 0.250，$n=40$，区间重叠）。

长度匹配在这里也不是细节，而是整个实验。这个运行的早期版本用了无文档 prompt（短约 900 个 token）并按末端对齐片段；于是 real 臂与错误文档臂都读数 0.200——这是两个臂被旋转相位偏移以同样方式破坏的特征，很容易被读成没有作用。有了长度匹配的接收方，每个位置都保持索引，两条序列在片段外完全相同，并且在打补丁之前先验证供体和接收方的问题片段逐 token 相同。

因为接收方已经持有一份文档，这种替换满足 $h_{\text{recv}}(\text{span})+d(\text{span})=h_{\text{skill}}(\text{span})$：它就是 $\alpha=1$ 的 $h_{\text{recv}}+d$。这使本节其余部分成为可能。

**它完整地携带作用。** 图 1 把两个通道在同一模型、同一分解上并排放置。在提示末位置，五个臂——包括把整个状态替换为有文档状态——都在 0.050 到 0.150 之间，无文档基线为 0.050。在文档自己的片段上，修复后同一个内容向量给出 1.00，接收方为 0.00（$n=16$，4 个计算器）。

修复前同一面板在 20 道题上读数 0.950，$\rho=1.06$：移植与文档在一道题上不一致，而移植答对了。这里每个接近或高于 1 的 $\rho$，诚实的读法是「与把文档放在 prompt 中无法区分」。

**交接在多深的地方有效（修复前）。** 在同一构造上移植**文档自己的**状态，到第 12 层都恢复文档的全部作用，然后掉下悬崖（表 C6）。第 0 层近乎同义反复——某层在文档 token 上的输出离「把这些 token 放回去」不远——所以承重的是第 8 和第 12 层，网络的三分之一处，接收方已经在这些位置上处理了八或十二个 block 的填充内容，而移植仍然恢复全部。过了第 14 层单层就不再够用：第 15 和 16 层 $\rho=0.14$，第 24 和 30 层 0.00。在**每一层**同时写入片段又回到 $\rho=1.00$，所以过了第 14 层失败的是单一深度上的交接，而不是机制。

**剖面可复现；它唯一的异常不可复现。** 我们在同一批题上换用另一个接收方（单一固定错误技能，而不是各技能的配对对照）第二次运行扫描，两者在第一次运行表现正常的地方都一致：第 0 层 +1.00 对 +1.00，第 4 层 +1.06 对 +1.07，第 8 层 +1.03 对 +1.14，第 12 层 +0.81 对 +1.00（表 C6b）。第一次运行中唯一的凸起——第 18 层 $\rho=0.07$ 对第 20 层 0.29——没有保留：复现在第 20 层给出 +0.16，低于它自己的第 16 层。我们读剖面而不读单个层，并把那个凸起读作噪声。

存活的窗口是**相对**深度上的窗口：这里是 36 层中的 0–12 层，合成层上是 28 层中的 0–10 层，都在约三分之一处。

**它表现得像机制，而不是扰动。** 四项对照，都在第 8 层，都在图 1 中，都在错误文档从不救回的计算器上读。

**剂量**：修复后 $\alpha=0.4, 0.5, 0.55, 0.6, 0.7, 1, 2$ 给出 $\rho=0.06, 0.00, 0.06, 0.62, 0.94, 1.00, 0.81$（$n=16$）。过渡是阶跃而非斜坡——一半内容并不比没有好，因为这时状态是两份连贯文档之间的中点，不对应其中任何一个——超调代价很小。一个只需要「够大」的注入两点都不会表现出来。修复前同样的扫描读数为 0.17、0.03、0.17、0.88、0.97、1.00（$n=30$），一次更粗的扫描在 $\alpha=0.5, 0.75, 1, 2$ 上为 0.06、1.06、1.06、0.89，逐位置缩放范数后的剂量与之重合（两种方式都是 0.06 和 0.89）。

**迁移**：修复后，写在两份文档共享的前缀上，另一技能的向量给出 0.19，同样位置上本技能自己的向量为 0.94（$n=16$）；在 40 个计算器上，另一家族的供体 0.06、同一家族的供体 0.06，对照 0.73。修复前，把**另一个**技能的均值内容向量写在两份文档共享的前缀上给出 $\rho=0.06$，而本文档自己的向量写在**同样位置**上为 1.00。由于每个技能的向量都相对同一个固定对照取得，这个臂恰好就是那个技能自己的片段状态而不是混合物，所以它是迁移检验能采取的最干净形式；而配对对照使它成为关于内容、而不是关于打了多少位置补丁的陈述。

**顺序**：同一组向量在片段自身位置间打乱，修复后给出 $\rho=0.00$（$n=16$）、40 个计算器上 0.08（修复前 0.12）。片段不是一个袋子——哪个位置持有文档的哪一部分，是作用的大部分。

**范数**：按每个位置 $\|d\|$ 缩放的高斯噪声给出 $\rho=0.00$，恰好是接收方（40 个计算器上 0.10）。作用不是「往这些位置写进很大的东西」的结果。

**这四项在哪个子集上读，以及为什么这不是挑樱桃。** 在 10 个计算器中的 4 个上，接收方——一份错误的临床文档——已经能解对题目。修复前每个片段臂在那里都起作用：相关技能供体 $\rho=0.71$，无关供体 0.43，范数匹配**噪声** 0.14，而在接收方得零分的 5 个上分别为 0.00、0.06、0.00；把两组合并会把一个为零的迁移臂变成表面上的 $\rho=0.38$。修复后有 6 个计算器落在那一边；噪声在那里不再起作用（0.00，$n=24$），但另一技能的向量仍读数 0.47，而在 4 个限制集计算器上为 0.19：在那里是槽中的错误文档把模型带偏了，一个连贯的替换就让它退回到自己已知的公式。

这一切分以**接收方**为条件——接收方是对照——而不以任何干预臂为条件，所以它不可能制造出它被用来报告的对比；并且按计算器而不是按实例切分，因为「这个模型不借助文档就能做这个计算器」是计算器的性质。表 D3 给出全部 40 道题上每个臂的数值以供比较。

**它在四倍数量的技能上复现。** 上面的 10 个计算器是救回实例最多的 10 个，而「五个计算器上的二十道题」是最显然的停止阅读的理由。所以我们在 **40** 个计算器上运行电池，在更大的集合内重新计算限制而不是沿用。40 个中有 15 个是错误文档从不救回的，剩 60 道题——原来的三倍——每个臂都成立（表 2）：文档自己的向量恢复 $\rho=0.87$，同一向量只写在另一技能文档共享的前缀上 0.73，半剂量 0.06，另一家族供体 0.06，片段自身位置打乱 0.08，范数匹配噪声 0.10，零臂恰为 0.00，接收方恰为 0.000，同一家族供体 0.06（修复后重跑）。分离在 0.87 与至多 0.10 之间，材料是三倍，区间按计算器 bootstrap。

**并且它在文档失败的地方失败（修复前）。** 在持续失败格上——金标文档**没有**救回的题——同一层上同样的移植给出 0.100，等于接收方的 0.100，而文档自己为 0.025（$n=40$，10 个计算器；该次运行零臂读数 0.150）。通道搬运文档所做的事，包括什么也不做。一个只会帮忙的臂可以用笼统的「更努力」解释；这个不行。

**为什么它能携带而单个位置不能。** 在 40 个计算器上片段宽 415 到 1,630 个位置，与它要支撑的答案同一量级。这是 §3.1 容量陈述的正面一半，两者合起来给出本文所依据的规则：**补丁能搬运的，是装得进它被给定的位置里的东西。** 一 token 的答案装得进一个位置；思维链除了一组与文档本身一样大的位置之外哪里都装不下。

### C.12 携带作用的向量由什么构成（完整）

文档片段上的向量复现了文档的全部作用，所以它由什么构成是可回答的，而不是猜测。四种分解，都在第 8 层。**除非标注「修复后」，本小节数字都来自修复前的 10 计算器开发运行**，对照接收方的 0.175 和文档的 0.950；凡有重跑的地方给出重跑结果并以其为准。

**不是共同位移。** 对集合中**每一个**技能平均 $d$ 并写入这个平均值，给出 $\rho=0.11$，而文档自己的为 1.06。让这一点尖锐而不仅是阴性的，是这个均值占向量的比例有多大：相对同一个固定对照，两个技能的内容向量在每个深度余弦 0.48–0.56，与全技能均值的余弦 0.72–0.76，每个 $d$ 的 54–60% 能量落在这个均值上（表 C7）。**内容向量的一半以上指向一个什么也不携带的方向。** 这是 §3 中 $g$ 在末位置上平坦的 0.062 在片段层面的对应：在两个地方起作用的都不是在场。

**不是幅度。** 有信息量的检验是剂量曲线对其范数匹配的孪生曲线。在 $\alpha=2$ 时补丁状态为 $2h_{\text{skill}}-h_{\text{recv}}$，在第 8 层是有文档状态长度的 1.76 倍；逐位置把它缩放回 $\|h_{\text{skill}}\|$ 是 43% 的改变，而代价为零——两种方式 $\rho$ 都是 0.89。在 $\alpha=0.5$ 时状态是 0.88 倍，缩放同样无代价（都是 0.06）。

我们也做了反向操作，把有文档状态缩放到**接收方**的范数，它什么也没改变（$\rho=1.06$）——但这个臂没有信息量，我们报告它只是为了说明这一点：两者范数在第 8 层只差 3.5%，几乎算不上操作。承载论点的是 $\alpha=2$ 的比较。剂量曲线与其范数匹配孪生在我们跑过的每个 $\alpha$ 上都重合（0.5：0.350 对 0.350；2：0.875 对 0.875；3：0.675 对 0.650）。文档的作用由其片段状态所指的方向携带，而不是由沿该方向走多远携带。相应地，范数匹配的高斯噪声给出 0.100，低于接收方。范数臂在修复后没有重跑。（表 2 中紧挨移植的那个臂 0.73 不是范数操作：它是迁移检验的配对对照，即本文档的 $d$ 只写在另一技能文档共享的前缀上。）

**随 $\alpha$ 分级，而过渡是阶跃。** 修复后，在 10 个开发计算器上（$n=16$），$\alpha=0.4, 0.5, 0.55, 0.6, 0.7, 1, 2$ 给出 $\rho=0.06, 0.00, 0.06, 0.62, 0.94, 1.00, 0.81$：到 0.55 为止在接收方水平，到 0.7 已达文档水平。修复前同样的扫描读数为 0.17、0.03、0.17、0.88、0.97、1.00（$n=30$，限制较宽松），更早的一个接收方在 $\alpha=0.5, 0.75, 1, 2$ 上给出 −0.14、+1.03、+1.03、+0.86（图 C2，修复前）：一半内容不比没有好，而四分之三已是作用的大部分。过了 $\alpha=1$，恢复缓慢衰减而不是断裂；在做了细网格的另一个接收方上，范数固定时它以同样方式衰减（$\alpha=2$：普通 0.875 对缩放 0.875；$\alpha=3$：0.675 对 0.650），所以超调的代价不是状态的大小。

**局部化，而且在人们会猜的那一段。** 只在片段的一部分上写入 $d$，可以在不改变任何一个 prompt token 的情况下把作用定位在文档内部——长度、位置、旋转相位都不变，变的只是哪些状态被覆盖。按两半（修复前），前一半给出 $\rho=1.06$，后一半 0.28，前一半与整段片段在 20 道题中的 18 道上逐题一致。按四段：

> | 片段的四段 | $n$ | 第 1 段 | **第 2 段** | 第 3 段 | 第 4 段 |
> |---|---|---|---|---|---|
> | 40 个计算器，修复后 | 60 | 0.12 | **0.56** | 0.12 | 0.12 |
> | 10 个计算器，修复后 | 16 | 0.12 | **0.81** | 0.06 | 0.06 |
> | 10 个计算器，修复前 | 20 | 0.28 | **0.83** | 0.11 | 0.44 |
> | 同样 40 个计算器上的对照（表 2） | 60 | 半剂量 0.06，打乱 0.08，噪声 0.10 | | | |

这些文档让结果可以解读，因为 10 份文档的章节顺序都相同：标题、*Required Inputs（所需输入）*、*Computation（计算）*（有时前面有 *Unit Conversion（单位换算）*）、*Calculation Tool（计算工具）*、*Example（例题）*。按干预实际使用的单位——片段内的 token 位置，而不是字符——计算部分的**标题**落在片段的 0.18–0.42 处，*Calculation Tool* 在 0.47–0.70，*Example* 在 0.61–0.79。所以对全部 10 份文档，第二段都是计算部分的**正文**，即公式本身；第一段是标题、输入列表以及最多该部分的开头；第三段是 Python 函数签名和例题的开头；第四段是例题的其余部分。

这样读，流程核心携带作用的大部分，其余每一段单独都在对照地板上。修复和更大的集合改变了两件事。例题在修复前读数 0.44，修复后为 0.06 和 0.12：**我们撤回「它携带的作用约为公式的一半」这一早先说法。** 并且公式单独在 10 个计算器上为 0.81，在 40 个计算器上为 0.56，而整份文档为 0.87，所以在更大的集合上其余三段虽然单独都不重要，组合起来却有作用。段落边界是近似的、随计算器变化，所以我们报告四段和章节图，而不声称精确对齐。

打乱片段自身的位置——保留向量的多重集，只破坏向量与 token 之间的对应——修复后在 40 个计算器上给出 0.08（修复前 0.21）：几乎全部作用都在这种对应之中。

**当允许向量包含任务信息时。** 在本文其他地方使用的 prompt 格式下，这个问题不会出现：文档在问题之前，所以其状态只是文档的函数，我们验证过它们在同一技能的实例间一致（等长 prompt 逐比特相同，否则余弦 ≥ 0.997）。为了问向量**能够**携带任务时会怎样，我们把文档移到问题之后，保持答案格式指令在最后，并用填充 token 补齐每个实例的问题，使文档对同一技能的每个实例都从同一个绝对索引开始——否则来自另一实例的供体会以错误的旋转相位写入，即 §4 描述的错误。这种格式在行为上几乎无代价（文档价值 0.025→0.925，而不是 0.025→0.950），并把接收方自身基线提高到 0.350。

在这种格式下向量**能够**携带任务，而在第 8 层它并不使用任务（与这里的一切一样，在错误文档从不救回的计算器上读）。修复后（$n=28$，7 个计算器），本实例自己的向量恢复 $\rho=1.00$，同一技能其他实例向量的均值 1.00，单个其他实例的向量 0.96，正交残差——这份病历特有的一切——0.04。修复前（图 C3）同样的臂读数为 1.00、1.00、1.06 和 0.00。到第 16 层情况变了：本实例自己的向量仍恢复 0.85，但其他实例向量的均值为 0.63，单个其他实例的为 0.48，而残差单独仍为 0.04。到第 16 层，文档在后的片段持有了问题中的某些东西，而其他实例的向量缺少它、残差单独也补不上。

几何同意并说明了原因，而且在任何注入之前：这种格式下两个实例的 $d$ 之间余弦在第 0 层为 0.998，第 8 层 0.984，到第 32 层 0.914，沿实例均值的能量占比从 0.997 降到 0.880。第 8 层向量 98% 是共享的，所以几乎没有实例特有的部分可用；第 32 层剩下的 12% 是否会起作用，是我们能提出但尚未回答的问题。

其他一切在两种 prompt 顺序间都复现（修复前）。另一技能的向量恢复 0.18，所有技能的均值 0.06，片段位置打乱的同一组向量 0.00，范数匹配噪声 0.00；缩放到接收方自己的范数无代价（0.99）；片段前一半携带 1.05，后一半 0.43，与文档在前格式所显示的同样集中在公式上。

**文档放在哪里，改变交接能到多深。** 把文档放在问题之后会移动悬崖。我们最初把它报告为一个被证实的秩预测，理由是文档在后片段在第 16 层之后参与比为 28–33，而文档在前格式为 14–17；§5.1 表明这两组数都是超大激活而不是表示，排除之后两种格式的维数相同且平坦。行为差异是真实的，而对它的秩解释撤回。

差异很大。在同一批题上、修复前，按各格式自身范围的比例：

> | 层 | 0 | 4 | 8 | 12 | **16** |
> |---|---|---|---|---|---|
> | 文档在前 | 1.00 | 1.07 | 1.14 | 1.00 | **0.14** |
> | 文档在后 | 0.99 | 1.11 | 1.00 | 0.93 | **0.80** |

两种格式到第 12 层都携带文档的全部作用。在第 16 层，文档在前格式携带其七分之一，文档在后格式携带五分之四；后者自己的悬崖来得更晚，在第 16 和 20 层之间（0.82 到 0.35）。在因果掩码下，放在前面的文档看不到问题，放在后面的文档能看到，所以文档在后片段的状态在被捕获时已经以问题为条件——这是显而易见的候选解释，我们没有检验。

修复后第 16 层的对比依然成立：文档在后 0.85（$n=28$），文档在前 40 个计算器上 0.19。修复前，在文档在后格式的第 0、12、16、20 层，同一技能其他实例的均值追踪本实例自己的向量（1.06/1.00、0.88/0.94、0.82/0.82、0.29/0.35），残差停在接收方水平；第 16 层的重跑（上文 0.63 对 0.85）没有复现这种一致，所以我们不再声称实例特有部分在深处从不起作用——只声称它单独什么也不做。

这排除的是「交接深度是网络固定性质」的读法：在模型、文档和题目都不变的情况下，改变 prompt 就能移动它。

### C.13 相关工作（详版）

**技能基准度量作用，不度量机制。** 2026 年的一批文献从行为上评估技能文档：跨领域（Li et al., 2026, SkillsBench）、在可执行的软件工程任务上（Han et al., 2026）、以及在不同投放协议下（Li et al., 2026, Skills Injector）；另一条平行路线研究检索哪个技能。动机上最接近的是把技能蒸馏进权重（Zhang & Qi, 2026），它问的是技能**可以**变成什么，而不是它在推理时已经是什么。这些工作都没有看前向传播内部，而它们报告的效应量正是我们 §7 表明可能依赖格式的那种。

**任务向量与函数向量，以及一个向量能携带什么的两个限制。** 上下文能被压缩为激活空间中单个方向，这在上下文示例上（Hendel et al., 2023; Todd et al., 2024）以及权重空间的微调上（Ilharco et al., 2023）已经确立。方法上我们属于这条线：我们的 $d$ 以同样的方式提取和再注入。对这种做法现已知有两个限制，而它们不是同一个限制。

Dong et al.（2026）证明了第一个。在线性 Transformer 中，注入一个任务向量在功能上是秩一映射，所以输入–输出关系为高秩的任务（例如双射）不能被单个向量编码；他们在 Llama-7B/13B 上证实，并通过在多个示例位置注入多个向量来修复。这个结果**解释了我们的一个结果**：在合成层上，$\bar d$——整个题集共享的一个向量，也就是可复用技能向量应有的样子——恢复 0.062，而它要编码的映射是一张 39 行的查找表。我们不把这个零结果当作新发现，而是归因于他们。

本文关心的限制不同，两者可以在经验上分开。在同一个合成层上，**本题自己的** $d_i$ 尽管面对同样的高秩映射，仍通过同一个单位置恢复 0.812，因为答案是一个 token；而在临床技能上同样的注入什么也恢复不了，因为答案有几百个 token。秩约束一个向量能表达哪些映射；长度约束任何小位置组能携带多少决策，与映射无关。Dura et al.（2026）把长度限制作为「顺序地而非在静态位置上修补思维链」的动机提出；§3.1 把它变成受控度量，§5.2 度量的是**表示**的秩而不是映射的秩。

我们在位置上也不同。函数向量和任务向量从一个位置读出、写入一个位置，并在答案为单 token 的任务上验证。Mehrafarin et al.（2026）展示了这可以推进多远，而对照我们的结果读，也展示了该位置持有什么：用取自模型**自己已完成的**思维链的状态修补单个靠后位置，至少 99% 的时候恢复正确的 GSM8K 答案，而我们的供体取自 prompt、在任何推理之前，什么也恢复不了。同样的位置、同样的干预；不同的是供体中答案是否已经存在。Da Silva et al.（2025）从另一个方向报告了同一通道的可靠性失败：在 36 个模型上，默认参数的函数向量只在 20% 的模型–任务对上恢复 5-shot 性能。

**什么时候一个向量**确实**够用，以及这说明了什么。** 单向量压缩最新最强的正面结果是 Ardoin et al.（2026）：他们学习指令 prompt 在中间层激活的加权和，把得到的**单个**向量注入到早层的一个占位位置，准确率损失不到两个百分点。我们把它读作一致而非矛盾，理由有两条，而且两条在这里都承重。第一，它成功的每个任务答案都短：首都、ISO 代码、大洲、年份、单词翻译、反义词、货币代码——全是单词精确匹配——以及单个字母的 ARC-Easy。这正是答案长度轴上我们自己的单位置补丁也有效的那一半（合成层上 0.812，§3.1）；它失败的那一半，他们的评测没有进入。第二，他们的最优配置在中间层提取、在**早**层注入——他们陈述的理由是早注入留下更多层去整合——这独立地与我们深度结果的方向一致（§5.1）。连同 Dong et al.（2026）和 Wiegreffe et al.（2025），三者给出一句话：单个向量是模型已有行为之间的**选择器**——他们的附录把九个任务编码进一个向量，约三比特——而不是需要上百个方向才能重建的内容载体。

**这里有三种不同的对象被称为「秩」。** 由于本文加了第四种，我们明确区分它们。Dong et al.（2026）约束**任务映射**的秩：一个注入向量能表达哪些输入–输出关系。Sarkar & Deka（2026）度量**雅可比矩阵**的秩，$\mathrm{eff\text{-}rank}\,\mathbb{E}_x[J_L^\top J_L]$——一层有多少方向因果地影响输出——并报告它是层内禀的，而且值得注意的是在 Gemma-2-2B 和 Gemma-2-9B 之间不变。Fernando & Guitchounts（2026）度量跨深度的**复合算子**的秩，发现它在 Llama-3.1-8B 中崩塌约 65 倍。我们度量的是一个**表示**的秩：一份文档在它自己的 $m$ 个片段位置上贡献的矩阵 $d\in\mathbb{R}^{m\times d}$。这个区分对我们结果的含义很重要。早期草稿把层内禀的因果容量（Sarkar & Deka, 2026）与 $d$ 的参与比从 64 降到 17 结合起来，论证交接窗口在**消息**一侧关闭；那次下降是超大激活（§5.1），排除后参与比是平的，所以我们撤回这一论证，也不知道窗口在哪一侧关闭。在这四者中，我们也是唯一截断被注入对象本身并读出行为的；另外三个分别用的是定理、一阶归因代理和对权重的谱手术。

对所有描述性度量（包括我们的）都适用一条告诫。Sun et al.（2024）记录了比中位数大三个数量级的激活，由一对固定隐藏维度在一小组 token 位置上携带，出现在单一层（Shi et al., 2026），并起偏置项的作用。在该层之后的残差流上算的谱统计量，是关于这些激活的统计量。我们自己的去中心化参与比在 Qwen3-8B 第 16 层四百个位置上读数 1.0，去掉四个位置后为 66（§5.1）；未去中心化的熵秩——也就是 Fernando & Guitchounts（2026）报告崩塌 65 倍的量——只会更容易受影响，因为那里超大成分也没有被中心化去掉。我们不声称他们的结果是伪影——他们的对象是复合算子，不是表示——但这个检查很便宜，我们认为应当成为标准。

**把文档压缩进参数或少数 token。** 一条平行路线用权重而非激活替代文档——从文档生成 LoRA 参数的超网络（Charakorn et al., 2026），以及在输出空间和隐藏空间同时做上下文蒸馏得到知识模块（Caccia et al., 2025）。它们在方法上与我们正交（权重加训练，对激活且不训练），但共享「文档作用可压缩」的前提。Wang et al.（2026）报告在这种内化之后重新提供上下文会**降低**准确率，这个现象正好可以用我们的 $t=g+d$ 拆分来描述：被内化的，与文档在场时贡献的，不是同一个对象。

**激活修补。** 关于修补能支持什么结论，我们遵循方法论文献（Zhang & Nanda, 2024; Heimersheim & Nanda, 2024）：移植确立充分性，屏蔽确立必要性，两者单独都不能确立一条路径。两个近期结果与我们接近，我们把它们读作一致的证据而不是竞争。Pola & Balasubramanian（2025）在只有指令片段不同的最小对比 prompt 之间修补，发现一个「起始」层，过了它干预就不再重要；我们在第 21 层的结果——过了它屏蔽文档无代价——是同一形状的发现，从相反方向得到（屏蔽而非修补），对象是文档而非指令。Li et al.（2025）论证可迁移的任务表示在时间上是局部的、即时组装的；我们的屏蔽对读取文档说了同样的话，因为没有单一位置组是必需的。Abdelsalam et al.（2026）同样把可恢复的因果信号定位到被改变的提示区域加少数中间 token，再在输出附近聚合。关于检索增强生成的机制研究（van Dort & Heuss, 2026）修补残差流来定位归因，但没有分离在场与内容。

### C.14 多项选择制造地板，并把检索与执行混在一起

我们的合成题有内容相同的两种形式：四选一的多项选择，和自由作答（「只给出数字」）。两种形式度量的不是同一个东西，而文献中有解释原因的机制。Wiegreffe et al.（2025）把答案**符号**的选择定位到单个中间层和每层一到四个注意力头：在多项选择中，决策被组装到一个位置、一个 token 上。这正是单位置补丁能搬运整个任务的机制，也是为什么在同一批题上我们的末位置通道在多项选择下读数 1.000，在思维链下读数 0.000。

检查小模型写了什么能解释上半部分（表 C8 上半）。没有文档时它复述问题中的数量（「2」）；有文档时它写出**表中的一个换算因子**（「21」「180」「60」）。它检索而不执行。只要检索到的数字能与某个选项匹配，多项选择就把检索算作成功，而位置先验又在上面提供 0.18–0.29 的地板。

下半部分是更尖锐的版本，而且是我们运行前登记的预测：如果多项选择形式能从文档结构而非数字解出，那么每个因子都被替换的表在自由作答中必须接近零分。它恰好是零。打乱行顺序在两种格式中代价都小，这也符合预期——我们的打乱是按行置换而表的每一行是一行，所以每个因子仍可检索，只是不在可读的顺序里。

两个推论。一个用多项选择格式跨模型规模比较技能效应的基准，度量的是一个组成随规模变化的混合物。而一个扰动文档并报告准确率下降的消融，在多项选择中度量的主要是文档是否还认得出是一份文档。

### C.15 合成层上的分解（完整）

**该位置的几何说的与行为相反。** 在干预之前，值得看看为什么显而易见的度量无法定案。在合成对照上，技能在提示末位置造成的位移与同长无关文档造成的位移之间，余弦在第 0 层 0.93、第 4 层 0.9475、第 10 层 0.91，直到第 18 层以后才降到 0.35–0.41——也就是模型停止读取之后。单独读，这说明注入不具内容特异性；对照表 C5 读则不可能如此，因为行为全是内容。分解解决了矛盾：在网络前半部分 $\|d\|$ 是 $\|t\|$ 的 0.38–0.45，所以这种余弦度量的大部分是共享的；直到第 16 层 $\|g\|$ 超过 $\|t\|$——错误文档把状态推得比正确文档**更远**，两个成分部分抵消。附录 B 给出完整图景。我们只用几何来选择干预什么，然后去干预。

我们把每个成分加回提示末位置的无文档状态，让前向继续：$h'=h_{\text{no}}+\alpha v$，$v\in\{d_i, g_i, t_i, \bar d, d_j\}$。上参照是把状态直接替换为 $h_{\text{skill}}$；下参照是不干预。

图 C1 是该几何的因果对应（数字见表 D10）。其中四条曲线值得分别读。

**在场成分什么也没修复**——第 20 层以后每一层都是 0.062（48 道中的 3 道），之前为 0.00–0.02。它不是无作用的噪声：单独注入时，它把全集准确率从无文档基线 0.180 降到 0.145，也就是真把错误文档放进 prompt 的准确率。在救回格上它给出 0.062，上下文中的错误文档也给出 0.062。它忠实复现了「有一份文档在场」的行为，而那种行为比没有文档更差。

**内容成分修复了该格的大部分**——第 26 层 0.812，上参照 1.000，而它曾被附录 B 中每一项几何度量当作小残差忽略。

**在一个补丁位置上它是量级不足，而不是不完整。** 剂量响应单调且陡峭——$\alpha=0.5, 1, 2$ 给出 0.31、0.81、0.98——所以 $\alpha=1$ 时缺的 0.19 是沿正确方向的量级不足，这在预期之中：$h_{\text{wrong}}+d_i$ 恰好是 $h_{\text{skill}}$，而把 $d_i$ 加到 $h_{\text{no}}$ 上会落到别处。这一点不能推广到更多位置：在自由作答中 $k=16$ 时，剂量在 $\alpha=1$ 与 2 之间是平的（0.232、0.268），从未接近完全替换的 0.554。两个成分在构造上可加，在效果上不可加。在每种配置下都存活的是不对称性：$g$ 单独在每个 $k$、每层、每个 $\alpha$ 上都无作用。

**接收方无关紧要，而单个共享向量不够。** 把 $h_{\text{skill}}$ 注入已经持有**错误**文档的 prompt 给出 0.979–1.000，与注入无文档 prompt 相同——无论周围 700 个 token 贡献了什么，末位置都不需要它。但 $\bar d$，整个题集一个向量，也就是「可复用技能向量」的含义，从第 21 层起只恢复 0.042–0.146，而本题自己的为 0.479–0.812。把 $d_i$ 沿 $u=\bar d/\|\bar d\|$ 和与之正交的方向拆开、分别注入，把两者分离，并在第 21 层翻转了答案：过了该层，平行一半携带约 0.9 的范数和 0.05 的作用，正交一半携带 0.44 的范数和 0.81 中的 0.60；在此之前两者互换，而那正是 §7 独立识别出前向传播受扰动的层段。

**补丁复现了文档完整的行为签名，而不只是它的成功。** 在全部四格上，把末位置替换为 $h_{\text{skill}}$，在 1.7B 第 26 层对救回/持续/保持/破坏给出 1.000 / 0.000 / 1.000 / 0.000，在 8B 第 30 层给出 1.000 / 0.024 / 1.000 / 0.000——逐格就是文档本身按格的定义所做的事。它复现技能的失败和破坏，与复现其修复一样忠实。加 $d_i$ 给出 0.812 / 0.112 / 1.000 / 0.125 和 0.864 / 0.024 / 1.000 / 0.077：同样的签名，衰减了。只会帮忙的补丁可以用笼统的「更努力」解释；同时恰好破坏文档所破坏的题的补丁，携带的是文档的决策。在场成分对**它自己的**文档通过了匹配检验：$h_{\text{no}}+g$ 在救回格上得 0.062，而上下文中的错误文档也得 0.062（1.7B），8B 上则是 0.250 对 0.250，跨四种不同的对照文档（附录 A）。

## E 实验细节（Experimental detail）

**模型与数值。** Qwen3-1.7B（28 层，$d=2048$）和 Qwen3-8B（36 层，$d=4096$）；§5.3 另加 Qwen3-0.6B（28 层，$d=1024$）和 Mistral-7B-Instruct-v0.3（32 层，$d=4096$），后者的对话模板没有 system 角色，所以系统文本被并入 user 轮。全程贪心解码，`enable_thinking` 关闭，并用对渲染后模板的自检验证。凡是操作 attention mask 的地方都用 eager attention，因为 sdpa 和 flash 会静默忽略 4D mask；层输出 hook 与实现无关，所以解码密集的运行用 sdpa，在 2k-token prompt 上约快 2.5 倍。1.7B 合成运行用 fp32：bf16 会在尾部 token 的对数概率上造成 0.5–2.5 nats 误差，而这里每个对数概率量都是这类数的差。8B 运行用 bf16，我们从中报告的差距是 5–8 nats，远超该误差；准确率通道无论如何都不受影响。

**自检，以及一个失败的自检。** 三项检查随实验一起运行。(i) **自移植**：供体和接收方是同一次前向，所以补丁必须是严格的无操作。在 fp32 合成运行上，每层偏差 0.0 nats。在 bf16 的 8B 运行上最多 0.38 nats——两种序列长度下的 bf16 运算——而准确率通道在每层仍是严格无操作，这就是我们区分两者的方式。(ii) **最后一层补丁**：替换最后一层在补丁位置的输出，按构造使该位置的 logits 成为供体的，所以下一个 token 必须完全一致。(iii) 屏蔽实验的**查询侧对照**。

**一个值得记录的错误。** 真实技能打分代码的第一版在「prompt **加**答案」的前向上对索引 −1 打补丁，那是答案的最后一个 token——在每一个被打分 logits 的位置之后。每个臂都返回未被触动的基线，精确到六位小数，这也正是它被发现的原因。只要捕获和打补丁之间前向长度会变化，相对索引就是错误的默认选择。

**对照文档。** 合成对照由 `make_controls.py` 从技能文档生成，它检查两件事：被破坏文档的数字不能与任务集的金标答案重合（249 个中有 7 个重合，2.8%），打乱不能是恒等置换。三种对照都以同一文件名存放在不同目录下，因为注入器从文件名主干生成「# Skill: *name*」标题——一个叫 `SKILL.zorb-units.corrupted.md` 的文件会在 prompt 中暴露操作，那样对照与处理就在两方面不同。

**题集。** 合成题集由换算表生成，数值范围 2–40，删去答案也出现在文档例题中的题（$n=358$；扫描使用前 120 或 200 道）。干扰项是误读换算表能得到的值——相邻行、错误家族、方向颠倒——从不用随机数，并且正确选项在 A/B/C/D 间轮换，使有位置偏好的模型仍然只能得到随机水平。
