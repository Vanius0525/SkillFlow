# 故事线 v3（2026-09-12 晚，取代 v2）

改写的三个理由：
(a) **秩塌缩被证伪为测量假象**（massive activations），v2 的 §5 整段作废；
(b) 样本量扩到 40 个 calculator / 59–60 题，模型阶梯做出来了（0.6B / 1.7B / 8B）；
(c) 预注册的「膝盖不随宽度走」被验证，这是全文最强的一个定量结果。

---

## 一句话

> 一份 skill 文档的作用**装不进模型答题的那个位置**——那里装的是「决策」，
> 决策的大小由答案占多少 token 决定。它装在**文档自己的 token 上**，
> 在那里它是一个**约一百个方向**的对象；这个数字**不随深度变，也不随模型宽度变**，
> 所以同一份文档在 0.6B 上要占掉残差流宽度的 4%，在 8B 上只占 1.2%。

三个量：**位置**（在哪）、**长度**（为什么单位置不行）、**方向数**（它有多大）。

## 与文献的关系（Introduction 里就要说清）

| 别人的主张 | 出处 | 我们的关系 |
|---|---|---|
| 单个 task vector ≡ rank-one 映射 | Dong et al., ICLR 2026 | 解释我们 `dbar`=0.062 的零结果；**但限制的是映射不是输出** |
| 一个学出来的向量能装下一条 prompt，掉点 <2% | Ardoin et al., 2607.08399 | **它测的全是短答案**；我们把长答案那一半补上 |
| 中层取、早层注最优 | 同上 | 与我们的深度结论同向，独立佐证 |
| 选择题把决策压进一个符号 | Wiegreffe et al., ICLR 2025 | 解释我们选择题上 1.000 的机制 |
| 用生成完的 CoT 补最后位置，GSM8K ≥99% | 2604.23351 | 最强正面佐证：答案已存在时搬得动 |
| massive activations：少数维度在少数位置上爆 100–1000× | Sun et al., COLM 2024；2605.08504 | **解释了我们自己一度当成机制的那个塌缩** |

**统一句**：单个向量是一个**选择器**（在模型已有的行为之间挑一个），
不是**内容的载体**（搬一份需要约一百个方向才能重建的新文档）。

## 章节骨架（v3）

### §1 问题与矛盾
行为上全是内容（gold 74.2 / no-skill 34.5 / wrong-skill 31.5），
几何上全是「有文档」（错误文档造成的位移与正确文档余弦 0.92–0.95）。

### §2 标准探针在真实任务上是空的 —— 原因是答案长度
最后一个位置上五条臂全部落在无文档基线。**内容不是不在那里**：
题干固定只换文档时，`d` 在 L6 能以 0.943 判断是十份文档中的哪一份。
**失败的是通道**：同模型同题只换答案格式 → 1.00 / 0.30 / 0.00。

### §3 能通的通道：文档自己的 span —— **现在是 40 个 calculator / 60 题**
恒等式 `h_recv + d = h_gold` 让移植**就是** α=1 的内容注入。
限制集（错误文档从不救活的 15/40 个 calculator，60 题）：

| 臂 | ρ |
|---|---|
| real（α=1） | **+0.87** |
| 范数重标定 | +0.77 |
| α=0.5 | +0.13 |
| 另一 family 的 skill | +0.04 |
| 同 family 的 skill | +0.12 |
| span 位置乱序 | +0.12 |
| 范数匹配噪声 | +0.13 |
| **恒等补丁（仪器地板）** | **+0.04** |

**剂量是阈值不是梯度**：α ≤ 0.55 贴地板（0.03–0.17），α ≥ 0.6 贴天花板（0.875–1.00）。

### §4 这个向量是什么做的
不是共同偏移（58% 能量，ρ=+0.06）；不是范数；**是 skill 不是 skill+task**。
文档内部可定位：计算段正文单独 0.80，函数签名 0.12，算例 0.43。

### §5 ★ 它有多大：截断秩（**全文最强的定量结果**）
- L8 上把 `d` 按 span 位置做 SVD 截断到秩 k 再注入：
  k≤16 全部贴地板，k=32 → 0.33，k=64 → 0.72，k=128 → 0.94；
  **保留最低 k 个方向精确为 0** —— 起作用的是头部谱。
- **膝盖不随深度下降**：L12 和 L16（doc-last）上膝盖都在 64–128。
- **膝盖不随模型宽度下降**（预注册）：Qwen3-0.6B（d=1024）膝盖仍在 32–64，
  k\*≈40，而「按宽度成比例」预测 k\*≈12。**证伪。**
- 推论：同一份文档占 0.6B 宽度的 4%、占 8B 的 1.2%。

### §6 深度悬崖：事实成立，**机制我们不知道**（并且撤回了一个）
- 充分性到 L12（ρ=1.00），L15 掉到 0.14；必要性到 L30+（屏蔽最后 6/36 层仍损失 0.50→0.30）。
- 悬崖在 **Qwen3-0.6B 上的相对深度相同**（0.32–0.43 对 0.33–0.42）。
- 文档放到题目之后，悬崖**后移四层**（L16 从 0.14 到 0.80）。
- **撤回**：v2 说「PR 从 64 掉到 17，所以表示被压成摘要」。
  那个塌缩是 massive activations：L16 起每份文档有一个 token 的范数达到中位数的 150×，
  由固定的两个维度（2276、676）承载，top-8 维占方差的 97.9%。
  **去掉 4 个位置（共约 400 个），PR 回到 66；逐位置单位化，回到 68。**
  0.6B / 1.7B 全深度没有这个现象（45–99），而悬崖照样存在。

### §7 测量陷阱（现在是四条）
1. 聚合 logprob 把无内容对照排在真状态之上；
2. 选择题制造地板（引 Wiegreffe 给机制）；
3. 错误文档对照的强度取决于它像不像，以及「模型本来就会」会伪造出部分迁移；
4. **残差流上的谱统计量在 massive activation 出现层之后不可读** —— 我们自己上过当。

### §8 仪器
- **完全确定性**：同一配置在两台机器上跑，360 个 item×arm 单元逐位相同。
- **恒等补丁不是行为上的恒等**：1306 对观测里 4.7% 翻面，25 上 37 下（符号检验 p=0.16）。
  所以 **小于约 5pp 的效应不可读**。
- `max_new` 900 vs 2400 在 1.7B 上 995 个单元逐位相同 —— 生成预算不是瓶颈。
