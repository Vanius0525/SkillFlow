## 第一部分：一句话该怎么说

如果只能说一句：

> **一份 skill 文档的作用不由「模型答题的那个位置上的一个向量」承载。**
> **它由文档自己的 token 承载；在那里，注入/减法/剂量/迁移这一整套因果实验全部成立。**
> **之前所有人都在一个装不下它的地方测量它——而装不下的原因是答案太长。**

三句话版本（对应论文三章）：

1. **负结果 + 诊断。** 在真实任务上，往最后一个 prompt 位置写任何东西都没用（八条臂全部
   落在「无文档」基线上，包括把整个状态换掉）。原因不是内容不在那里——它在那里且几乎完美可解码
   （41 类线性可分 0.93–1.00，chance 0.024）。原因是**一个位置只能搬运模型的「决策」，
   而一个占几百个 token 的决策塞不进一个状态**。把答案格式从思维链换成单 token 选择题，
   同一个探针立刻从 0.000 变成 1.000。
2. **找到能通的通道。** 文档自己的 token span。长度匹配替换后，被救回的题从 0.00 → 0.95（层 8）。
   而且因为长度匹配的接收器**本身已含一份文档**，这个替换在数学上**就是** α=1 的内容向量注入。
   于是整套向量实验第一次在真实 skill 上跑通，而且**每一条对照都落在地板上**
   （限制到「错误文档从未解决过的 calculator」，n=20，接收器 0.000，gold 0.900）：

   | | ρ | | | ρ |
   |---|---|---|---|---|
   | `real`（α=1） | **+1.06** | | `dall`（共同偏移） | +0.11 |
   | `realm`（共有前缀，配对对照） | +1.00 | | `dshuf`（乱序） | +0.11 |
   | `a0.5`（半剂量） | +0.06 | | `dfar`（无关技能） | +0.06 |
   | `a2` | +0.89 | | `dnear`（**近亲**技能） | **+0.00** |
   | | | | `drand`（范数匹配噪声） | **+0.00** |
3. **这个向量是什么做的。** 不是「共同偏移」（跨技能均值单独注入 +0.00，尽管它占了向量能量的 58%）；
   不是范数（重标定到接收器的范数，效果不变，ρ=+1.03）；在文档排在问题之前的格式下，
   它**逐位不含任何任务信息**（验证过 token id 与状态逐位相同），却足以复现全部效应。
   把文档挪到问题之后、让它**有机会**携带任务信息，它依然不用：
   **换一道题的向量（+1.04）和用自己的（+1.00）一样好**，题目专属那一半（+(-0.04)）恰好落在基线上。
4. **在文档内部还能继续定位。** 只把 `d` 写进 span 的某一段，prompt 一个 token 都不动：
   第 2 个四分位（正是 Computation 公式段）单独就给 **+0.80**，
   标题＋输入段 +0.25，函数签名段 +0.12，算例段 +0.43。
5. **有一个混淆是我们自己抓出来并修掉的。** 在模型本来就会做的那 5 个 calculator 上，
   往 span 里写**任何**东西都管用——**连纯噪声都有 +0.14，近亲技能有 +0.71**。
   那是扰动，不是迁移。所有因果臂因此只在「错误文档从未解决过的 calculator」上读；
   这个划分只依赖接收器（一个对照），不依赖任何干预臂。汇报时要主动讲这一条。

## 第二部分：怎样汇报（给不同听众的三个版本）

### A. 对导师/合作者（5 分钟）

按「负结果 → 诊断 → 正确通道 → 内部构成」四步讲，**每一步都带一个对照**：

| 步 | 主张 | 决定性的对照 |
|---|---|---|
| 1 | 最后位置的向量通道在真实任务上是空的 | **整状态替换也不行**（0.15 vs 无文档 0.05）——排除「向量构造得不好」 |
| 2 | 原因是答案长度 | **同模型同题只换答案格式**：1.00 / 0.30 / 0.00 |
| 3 | 文档 span 能通 | **`self` 臂在每层都等于接收器基线**——仪器自检；**全层同时移植 = 0.95** |
| 4 | 向量不含任务信息却充分 | **token id 逐位相同 + 截断后前向 reldiff = 0.0** ——不是论证，是量出来的 |

**不要**先讲几何（范数、余弦、PR）。几何在这篇里是**被推翻的那一方**：
它说「注入不是内容特异的」，行为说「全是内容」，全文就是在解释这个矛盾。

### B. 对审稿人（论文的自我辩护点）

预期会被挑的四处，以及我们已经准备好的回答：

1. **「n=40 太小。」** 承认，写进 Limitations。补强：四个独立 shard 各自算出的三个基线
   **完全一致**（0.950 / 0.025 / 0.175）；`self` 臂在 12 个层上全部落在基线上；
   深度曲线上单层的起伏（L18 0.250 vs L20 0.475）我们**明确说不解释**。
2. **「只在 R 格上做因果，是选择性报告。」** 回答：R 是唯一有因果可测的格
   （其余三格里文档本身就没起作用或没需要）。并且我们在 F 格上跑了同一套臂，
   `real` 跟着 `gold_in_context` 一起落在地板上——**通道搬运的是文档的效应，不是正确性**。
3. **「文档 span 移植只是把文档 token 放回去，是同义反复。」** 三道防线：
   (a) 层 0 确实接近同义反复，所以我们把**层 8 和层 12** 作为承重结论；
   (b) `dcross` 用**同样的位置**放另一个技能的状态只有 0.225，而自己的是 0.925；
   (c) 打乱 span 内部顺序就掉到 0.225 —— 不是「放了点东西进去」就行。
4. **「PR 塌缩和移植失效同区间，是不是巧合？」** 我们**事先把它写成可证伪的预测**并测了：
   把文档挪到问题之后，PR 不塌缩（L16 之后 28–33 而非 14–17），移植在 L16 从 0.29 升到 0.72。
   秩和深度同向移动，而这个操纵不是为了移动其中任何一个而选的。

### C. 对领域外的人（一句话 + 一个类比）

「模型读一份说明书时，说明书的内容**留在说明书那几行字上**，没有被压缩成一个可以搬走的
『技能向量』。你能把整段说明书的内部状态搬到另一次运行里并完整复现它的作用，
但你搬不走它的任何摘要。而大家之所以一直以为能搬走，是因为大家都在只需要回答一个字的题上测的。」

## 第三部分：脉络（论文结构与每章的落脚点）

```
§1  引言          矛盾：行为全是内容，几何全是「有文档」
§2  设置          1100 题真实 skill（主）＋ 合成正对照（地板恰为 0）＋ 四格 R/F/K/B
§3  哪个分量起作用  t = g + d。g 惰性（0.062 ≡ 上下文里放错文档），d 有效（0.812）
§4  一个位置装不下  答案长度阶梯 1.00 / 0.30 / 0.00 —— 负结果的诊断
§5  能通的通道 ★   文档 span：0.03 → 1.00；剂量/迁移/乱序/噪声四个对照
§6  深度          充分性到 L15，必要性到 L30+；PR 在同区间塌缩；可证伪预测被确认
§7  向量的成分 ★   不是共同偏移（58% 能量，+0.03）；不是范数；不含任务信息却充分
§8  三个测量陷阱   聚合 logprob 反序；选择题制造地板；错误文档要「像」才有伤害
```

★ = 本轮新增，也是全文最有说服力的两章。

**每章的落脚点各是一句话：**
- §3：*减法要减一个长度匹配的错误文档，不是「无文档」。*
- §4：*激活补丁能搬走的是「决策」，决策的大小由答案的 token 数决定。*
- §5：*把同一个减法搬到文档自己的位置上，它就从 0 变成 1。*
- §6：*文档被读到最后，但交接必须在前三分之一完成；表示在那里失去秩。*
- §7：*向量里一半以上的能量是共同偏移，而共同偏移承载零。*
- §8：*聚合指标、选择题和「随便一个错误文档」这三个默认做法各自会给出相反的结论。*

## 第四部分：结论的落脚点（这篇到底主张什么）

**主张（strong claim）：**
> 在答案长于一个 token 的任务上，「skill 向量」在模型答题的位置上**不存在**——
> 不是难以提取，是那里根本没有足以复现效应的东西。
> 效应存在于文档自己的位置上，并且在那里可以被完整地加、减、缩放和移植。

**边界（我们不主张的）：**
- 不主张「in-context 文档的作用无法被向量化」。我们主张的是**在哪里**向量化。
- 不主张 PR 塌缩**导致**移植失效。我们给的是一个同区间的对应 + 一个被确认的预测。
- 不主张这些数字跨模型成立。全部因果结果是 Qwen3-8B（Tier A 的单位置通道另有 1.7B fp32）。

**对方法学的直接建议（这是最可能被引用的部分）：**
1. 在最后一个 prompt 位置做激活补丁，测到的是**模型已经决定了什么**；
   在短答案 benchmark 上这与「文档提供了什么」不可区分。
2. 要分开这两者，只有两条路：**用一个决策塞不进去的答案格式**，
   或者**把补丁放到文档本身所在的位置**。
3. 报告任何「内容分量」之前，必须说明你减掉的是哪个对照——
   同一批数据换一个对照，跨技能余弦从 0.10 变成 0.54。

## 第四部分之二：稳健性（这四条是我会主动拿去给 reviewer 看的）

1. **剂量阶跃定位在 α=0.5→0.6**（+0.06 → +0.89），且范数重标定的对照臂逐点落在原臂上。
2. **calculator 数翻倍（10→20）后主结果复现**：`real` +0.95、配对对照 +0.92、
   跨技能 +0.14、噪声 +0.08。
3. **仪器自身噪声有上界**：40 题里「把接收器状态写回去」这个恒等操作翻了 2 题（0.05）。
   bf16 + 900 token 贪心解码 + hook 强制 clone 会有极小概率改变轨迹。**≈1/20。**
4. **F 格（gold 也救不回来）上通道跟着文档一起失效**：gold 0.025 / `real` 0.100 / 接收器 0.100。
   一条只会帮忙的臂无法和「让模型更努力」区分开；这条臂不是。

以及一条负面的自我检查：`dperp`（题目专属分量）在 doc-last 的 L0/12/16/20 上分别是
+0.00/+0.06/+0.00/+0.06 —— **不存在某个深度让它开始起作用**，所以「向量是纯 skill」
不是层 8 的偶然。
