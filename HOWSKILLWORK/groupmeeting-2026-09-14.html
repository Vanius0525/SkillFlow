技能文档的作用，发生在它自己的 token 上

给模型一段技能文档（公式、流程、例题），准确率会上升。我们想知道这份提升在模型内部走的是哪条路。答案分两半：传统的「提示末位置」只装着模型的决策，装不下内容；真正携带作用的是文档自己占据的那段 token 位置。在那里，内容注入可以像机制一样被剂量、迁移、截秩逐项检验。

01

研究问题与思路

问题。「技能（skill）」类工作（SkillsBench、SRA-Bench 等）只测行为效果，没人回答文档在前向传播里做了什么。最直观的做法是比较有/无文档时的隐藏状态，但它立刻出问题：在提示末位置，换成一份无关文档时残差流的位移几乎一样（第 0–10 层余弦 0.91–0.95），而行为上金标技能 +39.7pp、错误技能 −2.9pp。几何说「全是在场」，行为说「全是内容」。

思路一：减法分解。把位移拆成恒等式 t = g + d：g = h_wrong − h_no（在场成分，有一份文档就有），d = h_skill − h_wrong（内容成分）。把各成分加回无文档状态，看模型行为，从而判断哪一半在起作用。

思路二：换位置。在末位置做这件事，多选题上成立、长答案上完全失败。原因是一个位置最多修正一个生成 token。于是我们转到文档自己的片段：接收方 prompt 用一份固定的无关临床文档逐 token 替换金标文档（长度一致、位置编码对齐），把供体片段状态写进去。因为接收方本身就有文档，这一步在数学上就等于 h_recv + d，即 α=1、分布在 m 个位置上的内容注入。于是剂量、迁移、截秩这些向量操作都能在真实文档上做。

核心规则。补丁能搬运的，是装得进它被给定的那些位置里的东西。

三个贯穿全文的读数规则

ρ
ρ = (acc(臂) − acc(接收方)) / (acc(供体) − acc(接收方))：该臂恢复了文档效应的多大比例。1 = 与把文档放进 prompt 无法区分，0 = 与接收方一样。区间按计算器聚类 bootstrap（同一计算器的 20 题共享一份文档，不独立）。
四格
按「无文档 → 有文档」对错变化：R 救回（错→对）、F 持续失败、K 保持、B 破坏。只有 R 格能证明文档起作用，四格混在一起的聚合量可能与 R 符号相反（见附录陷阱 1）。
限制集
只保留「接收方（错误文档）在该组内一题都做不对」的计算器。条件加在对照上，不加在处理臂上，因此不会人为制造对比。40 个计算器中剩 15 个、60 题。
仪器故障与修复（影响读数的前提） 零臂 = 把接收方自己的状态写回自己，理论上必须完全不改变输出。修复前在 Qwen3-8B 上它改变了 6.1% 的答案（1,766 对中 108 个翻转）。原因：捕获前向没传 attention mask、解码前向传了，对无填充单序列数学等价但走不同 kernel，第 8 层状态差 1.2%、第 34 层差 25%，长思维链会把差异放大。两处都传 mask 后零臂严格为恒等（80/80）。
本页凡是片段通道的数字默认都是修复后；修复前的结果标 修复前。
03

论证链：每一步回答上一步留下的问题

  1. 行为效应到底是内容还是在场？
    E1 减法协议：内容成分修复 0.812，在场成分 0.062（= 放错误文档的效果）。
  2. 那为什么在真实临床题上末位置什么都读不到？
    E2 答案长度阶梯：只改格式，1 token 答案 1.000 → 短数字 0.304 → 思维链 0.000。末位置装的是决策。
  3. 决策装不下，内容在哪里？
    E3 文档片段通道：移植 = α=1 的内容注入，ρ=0.87，剂量、迁移、打乱、噪声都像机制。
  4. 文档在哪一层被交接、在哪一层仍被读？
    E4：交接在 ~0.35 深度就结束，注意力到 ~0.8 深度仍然重要。窗口实验证明是「通道关闭」不是「一层不够」。
  5. 注入的对象有多大？
    E5 秩截断：需要约 50 个方向；只保留谱底部同样多方向无效。
  6. 这些结论能推广吗？
    E6：通道、特异性、分离在 2 任务 × 3 模型上都成立；悬崖深度与 k* 只在家族内稳定。
  7. 内容成分是什么东西？
    E7：不是共同位移、不是幅度、是技能不是任务（第 8 层）、集中在公式段。
  8. 为什么交接在那一层死掉？
    E8：我们曾以为是表示被压缩（PR 64→17），查明是超大激活伪影，已撤回。机制仍未知。

减法协议：哪个成分在起作用

设计
合成任务（多选，Qwen3-1.7B，fp32，n=200，救回格 48 题）。在提示末位置把 h_no 改成 h_no + α·v，v ∈ {d_i, g_i, t_i, 均值 d̄, 他题 d_j}，继续前向。上参照：直接替换为 h_skill。
结果
替换 1.000；内容 d 0.812；在场 g 0.062（与把错误文档放进 prompt 完全一样）；共享均值 d̄ 0.062。四格签名：替换 1.000/0.000/1.000/0.000，加 d 为 0.812/0.112/1.000/0.125——补丁连「文档会弄坏哪些题」也一起复现了。
对照选择
相对无关文档 d 修复 0.812；相对「数字全替换的同一文档」只有 0.23–0.31；相对「句子打乱的同一文档」0.19–0.29，相差 3–4 倍。不指明对照的「内容成分」不是一个有定义的量。
解读
几何上 d 只占位移的 38–45%，被当作小残差；因果上它才是作用本体。修复前（零臂在小模型上仅 0.7% 翻转，不影响结论）

答案长度阶梯：末位置装的是决策

设计
同一模型（Qwen3-8B）、同一文档、同一批题，只改答案格式：多选（1 token）、自由数值（2–4 token）、逐步推理（几百 token）。在末位置用 h_skill 整体替换，取最好的一层。
机制
120 题中没有一题金标答案是单 token（36 题 2 token、55 题 3 token、29 题 4 token）。一个位置的补丁最多修正第一个生成 token。修补最后 k 个位置：k=1/4/16 → 0.286/0.286/0.554，是容量而不是阈值。

文档片段通道，以及在里面跑的完整电池

设计
供体 = 有金标文档的前向；接收方 = 同一 prompt，文档逐 token 换成一份固定的无关临床技能（不是任何题的金标）。在第 8 层把供体片段状态写入接收方同一片段，片段外保持接收方状态。等价于 h_recv + d。
各臂
半剂量 h_recv + ½d；另一技能的 d（只写两份文档共享的前缀）；本文档 d 只写同一前缀（迁移的位置配对对照）；同一组 d 在片段内打乱位置；逐位置范数匹配噪声；零臂。
为什么限制
接收方本来就会做的计算器上，模型不需要文档，错误文档被替换后反而能「想起」公式——另一技能的向量在那里读数 ρ=0.47，而在需要文档的计算器上只有 0.19。混合读会把「释放」误报成「迁移」。
E4 · 正文 §5.1 · 附录 C.9

能交接的深度 ≠ 仍在读的深度

充分性
把第 L 层的片段状态移植过去还有没有效（每层单独做）。
必要性
累积注意力屏蔽：从第 L 层到最后一层屏蔽所有位置对文档 token 的注意力，看救回题还剩多少答对。（单层屏蔽测不出，下一层会补回来。）
窗口实验
只在一段连续层上写片段，其他层不写。MedCalc：8–11 层 1.00、12–15 层 0.96、14–19 层 0.38、16–35 层（20 层）0.11，等于单独写第 16 层。TheoremQA：0.90 / 0.73 / 0.45 / 0.21。过了交接点，写多少层都没用——通道关闭了，不是「一层不够」。

秩截断：被注入的对象需要多少方向

设计
对片段内容矩阵 d ∈ ℝ^(m×D) 去位置均值后做 SVD，保留均值、只保留前 k 个奇异方向再写入。k=1 等价于「一个任务向量写在每个位置上」再加一个变化方向。对照：保留底部 k 个方向（同样的秩，被丢弃的那一半谱）。
k* 定义
预注册：取 k=16 到网格内最大值区间的一半，在 log₂k 上插值。在 0.6B 跑之前登记的两种预测：k* 恒定（文档性质）或 k* ∝ d（0.6B 应在 k≈12）。

内容成分属于什么

不是共同位移
对所有技能平均 d 并写入，只恢复 0.11（文档在后时 0.06），而这个平均方向占每个 d 能量的 54–60%。一半以上的内容向量指向一个什么都不携带的方向。修复前
不是幅度
逐位置把状态缩放到接收方范数，ρ 1.06 对 1.06；α=2 时状态长 1.76 倍、缩放回去仍 0.89 对 0.89。修复前 修复后未重跑。
技能而非任务
文档在问题前时，因果掩码让同一技能 20 个实例的片段状态完全相同，天然不含任务信息。把文档放到问题后：第 8 层别的实例的向量 0.96 对本实例 1.00，逐题残差只有 0.04。但第 16 层：别的实例 0.48、其他实例均值 0.63，本实例 0.85，残差单独仍 0.04——深层片段吸收了问题里的东西，两部分单独都补不上。
集中在公式
按 token 把片段均分四段（描述 / 公式 / 工具签名 / 例题），一次只写一段。

04

附录里值得讲的实验

对照文档决定了「内容」测的是什么 修复前

合成任务上三种对照：无关文本 / 同文档行打乱 / 同文档因子全替换。放进 prompt 时救回格分别解对 0.062 / 0.625 / 0.729——一张数字全错的表在多选里仍能解对近四分之三。多选格式把「检索到像样的数字」算作成功：小模型有文档时写出的是表里的某个换算因子，而不是算出来的结果。换成自由作答，因子全错的表价值恰好为 0（预注册预测），行打乱仍保留 0.70（每行一个因子，仍可检索）。

陷阱：聚合对数概率把对照排第一 修复前

第 27 层对所有题平均，金标答案 log-prob：均值向量 −2.85 ＞ 填充 −5.20 ＞ 真实技能状态 −6.60 ＞ 无文档 −7.30 ＞ 错误技能 −10.29，而准确率是 0.256 对 0.436。拉平的分布永远不会给 −19 nats，也永远到不了 argmax。第 21 层按四格拆解，F 和 B 格贡献了差距的 133%，R 格上真实状态反而赢 2.5 nats。对混合题集报告聚合 log-prob，测到的主要是置信度校准。

错误文档对照 ≠ 无文档对照

救回题（n=40）上只改文档槽里放什么：无文档 0.025，非临床散文 0.250，配对中性文档 0.175，一份错误临床技能 0.150，金标 0.950。任何一份文档都会把题从地板上抬起来，所以「有 vs 无」同时测了在场和内容——这是所有片段臂都对照「持有文档的接收方」的原因。临床干扰比散文更伤的方向符合预期，但区间重叠，不当结果报。

方法边界：LogicBench

答案多为二值。按技能限制几乎为空，逐题 n=57：移植 0.75，但半剂量 0.44、另一技能 0.38、打乱 0.25，深度曲线没有悬崖（L0 0.93 → L16 0.49 → L20 0.33）。二选一答案下任何扰动都相当于重掷硬币，逐题限制又挑出靠运气失败的题。写进 Limitations，不写成「跨领域不复现」。

05

当前结论

成立
提示末位置的补丁搬运的是决策，不是文档内容。只改答案格式，单位置补丁 1.000 → 0.304 → 0.000；容量随修补位置数增长。
成立
文档作用经由文档自己的 token 片段传递。早中层整段移植复现文档效应（ρ 0.74–0.94，2 任务 × 3 模型），半剂量、另一技能、打乱、噪声都在地板附近（≤0.27）。
成立
充分性与必要性在深度上分离。单层交接在 0.2–0.4 深度处关闭（窗口实验证明是通道关闭），对文档的注意力到 0.56–0.88 深度仍然必要；在所有组合上成立。
成立
作用需要谱顶部的数十个方向。k ≤ 32 基本无效，底部 64 个方向无效；宽度比例预测（k≈12）在两个任务上被否定。
收窄
k* 与悬崖相对深度只在同一模型家族内稳定。Mistral 同宽 k* 64–84、悬崖 0.19–0.22。不再声称「k* 是文档的性质」；跨家族差异 MedCalc 显著、TheoremQA 不显著，且 Mistral 的 k* 受网格截断。
收窄
「技能而非任务」只在第 8 层干净成立。第 16 层另一实例向量只恢复 0.48（本实例 0.85）。
撤回
「例题贡献约为公式的一半」；「交接死亡处表示被压缩」；「实例特有部分在任何深度都不起作用」；旧稿把 realm 臂标成「按接收方范数缩放 0.73」（实为共享前缀配对对照），据此写的「部分依赖范数」同时撤回。

术语表

skill document技能文档
放进上下文帮助模型完成任务的短文档：流程、公式、查表、例题。
residual stream残差流
Transformer 各层之间传递的隐藏状态 h。
activation patching激活修补
把一次前向中某些位置、某层的状态替换或加进另一次前向，观察行为变化。
last prompt position提示末位置
prompt 最后一个 token，生成从这里开始；传统 patching 最常用的位置。
donor / receiver供体 / 接收方
提供状态的前向（有金标文档）/ 被写入状态的前向（文档换成固定无关临床文档）。
span · transplant片段 · 移植
一段连续 token 位置；本文特指文档所占位置。移植 = 把供体片段状态逐位置写进接收方同一片段。
g / d / t在场 / 内容 / 总位移
g = h_wrong − h_no，d = h_skill − h_wrong，t = h_skill − h_no = g + d。
α (dose)剂量
写入 h_recv + α·d；α=1 即有文档状态本身。
arm · null arm臂 · 零臂
臂 = 一种实验条件。零臂 = 把接收方自己的状态写回，必须严格不改变输出，用来检验实验仪器。
ρ恢复比例
(acc(臂) − acc(接收方)) / (acc(供体) − acc(接收方))。
R / F / K / B救回 / 持续失败 / 保持 / 破坏
按无文档→有文档的对错变化给题分四格。
restricted split限制集
只保留接收方在该组一题都不会的组；条件只加在对照上。
release释放
在模型本来会做的题上，扰动错误文档让模型想起已知公式，看起来像迁移。
realm共享前缀配对对照
本文档 d 只写在与另一技能文档共享的前缀上；与「另一技能 d 写同一前缀」（dcross）比较，隔离供体身份。
handover交接（充分性）
第 L 层移植仍能恢复作用；「悬崖」= ρ 从 ≥0.5 跌到 <0.5 的相对深度。
knockout累积注意力屏蔽（必要性）
从第 L 层到末尾屏蔽对文档 token 的注意力；「仍在读」= 保留 ≥ 一半救回题的最浅相对深度。
rank truncation · k*秩截断 · 拐点
内容矩阵去均值 SVD 后只留前 k 个方向；k* = k=16 到网格最大值区间一半处的 k（log₂ 插值）。
participation ratio (PR)参与比
(Σλ)² / Σλ²，有效维数；本文用去中心化版本。
massive activations超大激活
固定少数维度、少数位置上比中位数大 2–3 个数量级的激活，在固定层出现，会主导谱统计量。
CoT / MC / pp / nats思维链 / 多项选择 / 百分点 / 奈特
pp = 准确率百分点差；nats = 以 e 为底的对数概率单位。
pre-fix / after the fix修复前 / 修复后
attention mask kernel 故障修复之前 / 之后产生的结果。
